## 1. 新手摘要

这次实验想知道：在事实数据库尚未开放前，能否先用一个明确标记为“候选”的追加式记忆层，让新事件 A 找回数月前相关事件 B，同时不偷看未来信息，也不把隔离项当成事实。  
我们原本预计：实体、事件类型、中文文本和时间的可解释混合评分，能让旧但相关的 B 排在近期无关材料之前；`known_at` 截止时间、隔离过滤和哈希链应当全部生效。  
实际看到：15项候选记忆测试全部通过；旧相关事件以`0.836229`排第1，近期完全无关事件仅`0.049360`；未来、补录倒灌、默认隔离和未复核候选均为0泄漏，裸复核状态及未获外部验证的自报哈希被拒绝，直接篡改日志被发现，命令行三步往返成功。全库71项测试通过。  
这说明：候选记忆的时间边界、状态隔离、追加审计和确定性召回已经形成可运行纵向切片。  
但还不能说明：本实验即使通过，也不能证明向量检索质量、生产吞吐、模型推理质量或事实入库安全。  
下一步要做：先实现最小候选记忆日志与确定性召回器，再按预注册夹具一次性运行负控和门禁。  

## 2. 研究背景

本实验属于 `RD-20260731T090245Z-main-KLCN`。DeepSeek V4 Flash 的跨文体 B2 有效结果 0/4 通过语义门禁，因此 PostgreSQL 事实写入继续后置；但长期记忆的时间边界、候选身份、追加审计和召回解释可以脱离模型能力先验证。这样既继续推进“A 唤醒 B”的设计意图，也不绕过 `DEC-20260731T163828Z-main-4RG9` 的事实批准边界。

## 3. 实验前假设

只验证一个候选层纵向切片：追加式候选记忆日志与确定性混合召回，能够在固定小型夹具中召回旧的相关事件，同时 100% 阻止 `known_at` 之后的信息和默认隔离项进入结果，并检测日志篡改。

## 4. 实验前预测

如果假设为真，应该看到：

- 指标：相关历史事件 B 在查询 A 的 Top 3 内；未来知识泄漏 0 条；默认隔离泄漏 0 条；日志篡改检出率 100%；相同输入重复运行排序完全一致。
- 召回行为：数月前具有同一规范实体和事件类型的记录，应排在数日内但实体、事件类型均无关的记录之前。
- 风险表现：每个命中必须返回候选状态、来源逻辑 URI、候选哈希和分项得分；接口不得提供 `approved_fact` 状态。
- 分段表现：中文文本重叠可提供弱信号，但实体和事件类型应为主要可解释信号；仅时间接近不能单独获得高排名。

## 5. 基准和对照

| 对照 | 用途 | 路径 |
| --- | --- | --- |
| 纯发布时间倒序 | 检查“近期但无关”是否会错误压过旧相关事件 | 测试夹具内确定性计算 |
| 取消 `known_at` 截止的负控 | 证明未来相关材料本来会高分，但正式查询必须过滤 | 测试夹具内确定性计算 |
| 默认排除与显式包含隔离项 | 验证风险状态过滤不是由分数偶然造成 | 测试夹具内确定性计算 |
| 篡改一行追加日志 | 验证记录哈希和前向哈希链能发现历史被改写 | `hot://experiments/EX-20260731T165756Z-main-L6RP/` |

## 6. 竞争性解释

即使结果符合预期，也可能是：

- 夹具过小且人工设置的规范实体 ID 已经直接给出答案，尚未证明真实世界实体消歧能力。
- 旧事件胜出可能主要依赖事件类型，而不是中文文本召回质量。
- JSONL 小数据表现不能外推 PostgreSQL、pgvector 或机械硬盘上的生产延迟。
- 候选记忆正确召回不等于候选内容为真，更不等于能正确推断事件 C。

## 7. 证伪条件

出现以下情况，本假设不通过：

- 旧相关事件 B 未进入 Top 3，或被近期无关记录压过。
- 任意 `known_at > as_of` 的记录进入正式结果。
- 默认查询返回 `quarantine` 记录。
- 修改历史记录后加载器没有报错。
- 追加同一 `memory_id` 能静默覆盖旧记录。
- 命中结果缺少状态、来源、候选哈希或分项召回理由。
- 代码或 Schema 允许将本层记录标成 `approved_fact`。

## 14. 反对证据

- 只有一个人工固定事件族，规范实体 ID 直接提供了强信号，不能代表真实实体消歧。
- 中文检索只使用连续双字片段，不是语义向量；同义改写、简称和跨语言关联尚未验证。
- 固定单组权重没有敏感性、真实Top K或来源多样性检验。
- JSONL是单写者开发实现，没有数据库事务、并发锁、崩溃注入、签名或异地head锚定。
- 没有机械盘，不能形成碎片化、吞吐或压缩段性能结论。

## 15. 偏差诊断

核心预测一致。执行后唯一偏差是“近期无关”夹具的辅助关键词最初误继承了默认相关词，使其词项分为`0.073529`而非0。该问题会削弱负控独立性，因此在不改变算法、权重和门槛的前提下清理夹具并重跑；清理后无关项总分从`0.122889`降至`0.049360`，相关项仍为`0.836229`。这属于测试有效性修复，不是结果后优化算法。
