## 1. 新手摘要

这次实验想知道：实盘策略在"市场不拥挤"时，是否应该把"看起来还很健康的旧仓"换掉去追当日动量第一的标的？以及，旧仓涨过头（超分）或今天在跌时，是否应该主动撤离而非被动换仓？

我们原本预计：当前实盘（v19，A2-slope004）在非拥挤环境下直接按 Top1 换仓，存在四个缺陷——①A2 非拥挤对旧仓零判断（卖强买弱）；②动量算法窗口滞后（看不见今天）；③超分旧仓无主动撤离逻辑；④今日可得信号在常态路径没用上。6/30-7/1 正好触发了全部四个：6/30 卖出全市场 91% 分位的 588220 换入 41% 分位的 159502；7/1 旧仓 159502 超分(6.99≥5)且今日跌-1.83%，却买入同样今日在跌(-1.87%)的 159967。

实际看到：待回测。预注册阶段先锁定假设、5+2 闸判据、证伪条件，避免看结果调参。

这说明：待回测。

但还不能说明：6/30-7/1 是触发案例，不能证明机制有效。那些"看起来健康实则马上崩"的旧仓若被误留会吃大跌；"今日否决"若过严会错过 V 型反转。必须靠历史样本 + 负控验证。

下一步要做：在回测平台跑全历史对照，验证撤离端 7 闸 + 进攻端今日否决是否在"不牺牲趋势市利润"前提下减少卖强买弱与追高接刀。

## 2. 研究背景

实盘 ETF 双池动量轮动策略 v19 在 2026-06-30、2026-07-01 连续两日出现"换入新标的当天即套"的亏损。经多轮假设验证（详见第 11 节触发背景，含 v2 归因修正），定位到**四个互相关联的根因**：

1. **A2 非拥挤旧仓零判断（真因A）**：实盘 `ETF双池动量轮动_MiniQMT.py:1879-1881`，`if not crowded: return Top1`——非拥挤时对旧仓做零判断，无条件追当日 Top1。
2. **动量算法窗口滞后（真因B）**：calc_score 的 25 天加权窗口对"几天前暴涨"反应过度、对"今天下跌"反应不足（159502 7/1 在跌但 score 反从 4.78 升至 6.99）。
3. **超分旧仓无主动撤离（真因C）**：旧仓 score≥MAX_SCORE 时被过滤，但既不保留也不主动跑，只机械换仓——卖的理由是排名非超分。
4. **决策路径不调今日信号（真因D）**：`check_topn_risk_veto`（今日盘中跌幅否决）已实现，但仅在拥挤/抗抖路径调用，常态非拥挤路径不调用——药在手边没吃。

本实验验证：在 A2 非拥挤分支加"撤离端 7 闸（含超分闸+今日信号闸）+ 进攻端今日透支否决"，能否在历史样本中减少卖强买弱与追高接刀、且不因该换不换而错过更大机会。

这是研究库空白：既有防御全在管"环境/市场"，没有管"单标的持仓健康度 + 今日盘中状态"。本实验填补这个空白。且经实测确认，滞后不能从算法内部治（加权/短窗/分钟数据都走不通，见 11.7），只能从决策层补救。

## 3. 实验前假设

**H1（撤离端）：在 A2 非拥挤环境下，若旧仓未超分、今日未急跌、趋势结构完整、仍在 TopN、ret20 为正、且与新 Top1 分差不大，则保留旧仓的全周期收益不低于现状无条件换仓，且最大回撤不恶化。**

**H2（进攻端）：新 Top1 若今日盘中已透支（暴涨）或在跌，则否决追入转空仓/货币基金，能减少追高接刀损失，且不因偶尔错过 V 型反转而净亏。**

一句话：健康的旧仓不该因动量分微弱落后被换走；涨过头/今天在跌的旧仓应主动撤离；今日透支/在跌的新标的不该追。

## 4. 实验前预测

如果 H1 为真，应该看到：

- **指标**：加常态保留后，全周期最终收益 ≥ 基准（v19 现状）或差距在可接受范围（如 -2% 以内）；最大回撤不显著恶化（如恶化 < 3pp）。
- **交易行为**：换仓次数下降（减少无谓折腾）；保留的旧仓后续 N 日收益 ≥ 被换入的新 Top1 后续 N 日收益（即在"卖强买弱"案例上确实避免了损失）。
- **风险表现**：因"该换不换"导致的大涨机会错过次数，应少于"避免卖强买弱"省下的损失次数。
- **分段表现**：在普涨市/结构性行情（dispersion 高）段改善明显；在单边趋势市段不显著恶化（趋势市旧仓本就容易保持 Top1，保留与否影响小）。

## 6. 竞争性解释

即使结果符合预期，也可能是：

- **市场本来就有惯性**：旧仓后续涨可能只是动量延续的自然结果，不是"保留机制"的功劳。需用消融（对照 B/C/E）隔离。
- **样本期偏倚**：本次触发期（2026 下半年）若恰好是高 dispersion 结构性行情多发期，保留旧仓天然占优；其他时期未必。需分段验证。
- **换仓摩擦省下**：收益改善可能纯粹来自少交易省成本，不是"避免了卖强买弱"。需对比换手次数与单位换手收益贡献。
- **看结果选参数**：闸阈值（gap/X/Y/Z）如果是看完 6/30-7/1 才定的，就是过拟合。必须预注册 + 参数网格 + 邻域敏感性。
- **随机性伪装**：收益改善可能是随机波动。必须用对照 F 随机负控证超额 ≠ 0（研究库硬规则）。
- **V 型反转错过**：进攻端今日否决可能正好卡在 V 型反转的最低点，错过反弹。需统计否决后 N 日收益分布。

## 7. 证伪条件

**H1（撤离端）不通过的条件（任一成立）：**

- **收益证伪**：对照 A 全周期收益显著低于基准（如 cost1x 下 -5% 以上，或 cost2x 下 -8% 以上）。
- **回撤证伪**：对照 A 最大回撤显著恶化（如恶化 > 5pp）。
- **核心权衡失败**：因"该换不换"错过的大涨机会收益 > 保留旧仓省下的摩擦 + 避免的卖强买弱损失（机制在帮倒忙）。
- **样本外失效**：样本外段收益显著低于基准。

**H2（进攻端）不通过的条件（任一成立）：**

- **负控失败**：对照 D 收益 ≤ 对照 F（随机否决），即进攻端否决的超额贡献无法与随机区分。
- **V 型反转损失过大**：因今日否决错过的 V 型反转收益 > 避免的追高接刀损失。
- **参数过拟合**：Y/Z 阈值高度敏感（网格 CV > 10%），或最优值恰好是看完 7/1 才能猜到的。

**通用证伪（两层共用）：**

- **参数过拟合**：任一可调参数（gap/X/Y/Z/TopN/ret20下限）网格 CV > 10%，或 U 型峰顶不成立。
- **多重比较未通过**：未报告完整搜索空间与失败样本数。

## 8. 撤离端：7 道闸设计（核心）

判断逻辑：**撤离端 7 道闸评估旧仓——超分闸(6)和今日信号闸(7)触发撤离标记；其余闸全过才保留，任一失败进进攻端评估。** 全部复用代码既有指标（`calc_a2_state_metrics` / `get_a2_metric_rank` / `check_topn_risk_veto` / `calc_score` / `MAX_SCORE`），零新数据依赖。

### 闸 1：旧仓趋势结构未破（必要条件）
- **判据**：`price > MA20 且 MA20 > MA60`（均线多头排列）
- **代码已有**：`calc_a2_state_metrics` 的 `above_ma20` + `ma20_gt_ma60`
- **含义**：均线破位 = 趋势确认结束，必须换。
- **6/30 验证**：588220 满足 ✓

### 闸 2：旧仓仍在 TopN 范围（防止死扛烂票）
- **判据**：旧仓 rank ≤ TopN（**候选阈值 Top5 / Top10，需回测定**）
- **代码已有**：`get_a2_metric_rank`
- **含义**：旧仓虽非 Top1，但未掉到无人问津。
- **理由**：防止"旧仓彻底掉队还死扛"。Top1 换 Top2/Top3 可保留，换 Top50 就是该换。

### 闸 3：旧仓无短期急跌（复用已有否决）
- **判据**：当日跌幅 < 3%、两日跌幅 < 5%
- **代码已有**：直接调用 `check_topn_risk_veto(current)`
- **含义**：旧仓今天在崩，不能因"以前健康"就留。
- **6/30 验证**：588220 当日 +5.64%，满足 ✓

### 闸 4：旧仓 20 日收益仍为正（趋势还有惯性）
- **判据**：`ret20 > 0`（**候选下限 0 或 +2%，需回测定**）
- **代码已有**：`calc_a2_state_metrics` 的 `ret20`
- **含义**：过去 20 天还在涨，趋势有惯性。ret20 转负 = 中期趋势已破。
- **6/30 验证**：588220 ret20=+22.67%，远超 ✓

### 闸 5：旧仓与新 Top1 的 score 差距不悬殊（防明显更好的机会被错过）
- **判据**：`top1_score - current_score ≤ gap`（**候选 gap，需回测定**）
- **代码已有**：scored 列表
- **含义**：新 Top1 确实比旧仓好不少才换，只好一点点别折腾。
- **6/30 验证**：588220(4.564) vs 159502(4.783)，gap=0.22，满足 ✓
- **特殊处理（7/1 暴露）**：若旧仓被 MAX_SCORE 过滤（score≥5，不在 scored 列表），score 差无法直接算。此时走闸 6 判断。

### 闸 6：旧仓超分即撤离信号（新增，源自 11.6 机制发现）
- **判据**：旧仓 score ≥ MAX_SCORE(5) → **撤离标记**（不保留，是跑的信号）
- **代码已有**：`calc_score` + `MAX_SCORE`
- **含义**：旧仓超分 = 涨过头的撤离信号，而非持有理由。
- **7/1 验证**：159502 7/1 score=6.99 ≥ 5，应触发撤离标记 ✓
- **理由**：修正 MAX_SCORE 的逻辑漏洞——超分本意过滤"涨太离谱"，当标的是旧仓时应解读为"该跑"而非"被动换仓的中间态"。

### 闸 7：旧仓今日盘中信号（新增，源自 11.8 决策路径滞后发现）
- **判据**：旧仓今日跌幅（vs 昨收）> -X%（**候选 X，需回测定**，如 -1%/-2%）
- **代码已有**：`check_topn_risk_veto`（已实现，复用到常态路径）
- **含义**：旧仓今天在跌，即使历史趋势还在，也是"今天在变坏"的真实信号。
- **7/1 验证**：159502 7/1 今日跌幅-1.83%，触发警惕 ✓
- **理由**：补 calc_score 看不见今日的盲区。今日信号在 13:05 已可得，零未来函数。

### 汇总判断（扩展版）

```
非拥挤环境下，评估旧仓：
  闸6触发(超分≥5) → 撤离标记（涨过头，要跑）
  闸7触发(今日跌>X%) → 撤离标记（今天在变坏）
  
  if 撤离标记未触发 AND 闸1(均线多头) AND 闸2(rank≤TopN) 
     AND 闸3(无急跌) AND 闸4(ret20>0) AND 闸5(score差≤gap):
      → 保留旧仓（健康，不折腾）
  else:
      → 进入进攻端评估（见第二层）
```

### 第二层：进攻端——新 Top1 今日透支/在跌否决（新增）

撤掉旧仓后，新 Top1 还要过进攻端否决（源自 11.5 复核铁证：6/30 头部 10% 标的 7/1 有 45.3% 下跌概率）：

| 否决判据（候选，需回测验证阈值）| 含义 |
| --- | --- |
| 新 Top1 今日盘中累计涨幅 > +Y%（如+4%）| 暴涨透支，追入次日大概率均值回归 |
| 新 Top1 今日盘中在跌 > -Z%（如-1.5%）| 跟随下跌，不接正在下落的刀 |
| 新 Top1 近 N 日已连续大涨（如5日>+15%）| 动量末端 |

```
进攻端：
  if 新Top1 今日透支 OR 今日在跌 OR 近期连涨过头:
      → 否决追入，空仓或转货币基金 511880
  else:
      → 按Top1买入
```

**7/1 若有这套逻辑**：159502（超分6.99+今日跌-1.83%）→ 撤离标记；159967（今日跌-1.87%）→ 进攻端否决 → **结果应是空仓/货币基金，而非换到159967。**

### 设计原则

1. **全部复用既有指标**：所有闸用的 `above_ma20 / ma20_gt_ma60 / ret20 / score / rank / risk_veto / current_price` 全是代码每轮选股已在算的，不引入新数据依赖。
2. **保守取向**：撤离端"全过才留，任一失败进进攻端评估"；进攻端"任一透支否决"。默认偏向空仓（最保守），最坏退化成 v19。
3. **不预测拐点**：测量旧仓/新标的今天的客观状态（今日跌幅、超分与否是事实），不猜测"明天会不会跌"。与 MCYG/L2/L4 证伪的"预测拐点"划清界限。
4. **今日信号补救算法滞后**：calc_score 管"过去25天涨得猛不猛"（保留动量本质），闸7/第二层管"今天是不是已变坏/透支"（补今日盲区）。各司其职，互不破坏。
5. **可调参数有限**：闸5的gap、闸7的X、第二层的Y/Z/N做参数敏感性网格 + 报告完整搜索空间。其余闸阈值是客观结构性条件。

### 11.6 机制发现：超分旧仓无主动撤离逻辑（真因C，新增）

精确复算揭示一个被忽视的逻辑漏洞：

- 6/30：159502 score=4.78 < 5（进 scored，排 Top1 被买入）
- 7/1：159502 score=**6.99 ≥ 5**（被 MAX_SCORE 过滤，不在 Top3）

**MAX_SCORE 过滤本意是"剔除涨太离谱的标的"，但当这个标的是旧仓时，策略陷入矛盾**：
- 不选它做新标的（因超分被过滤）✓ 合理
- 但**既不保留它**（不在 Top3，A2 非拥挤直接换 Top1）也**不主动撤离它**（无"超分即跑"逻辑）
- 结果：它被机械地"因排名换掉"，**卖的理由是排名，不是它超分了**

正确逻辑应是：**旧仓超分（score≥5）= 涨过头的撤离信号，而非持有或被动换仓的中间态。** 这修正了 v1 归因的盲区，也是 5 闸方案需扩展为"超分闸"的依据。

### 11.7 死胡同实测：加重近期权重治不了滞后（用户假设证伪）

用户提出"近期权重越大越能减少滞后"。主控用 159502 的 7/1 序列实测四种加权方案（全部 26 点，含 7/1 的 1.605）：

| 加权方案 | 159502 的 score | 标的实况 |
| --- | --- | --- |
| 现版 线性1→2 | 6.99 | 7/1 在跌-1.8% |
| 线性1→3（更陡）| **9.97 ↑** | 分数更高 |
| 指数衰减λ=3 | **39.12 ↑** | 飙升 |
| 指数衰减λ=5 | **64.75 ↑** | 飙升 |
| 近5天短窗口 | 37.58 ↑ | 飙升 |

**标的在跌，加重近期权重后分数反而飙升。** 机制：6/29 暴涨 +7.6%（1.548→1.633）在窗口内，越加权近期越放大它对斜率的拉抬。加权回归"让近期点贴近拟合线"，而近期点恰含暴涨+走平+小跌，把"过去几天涨过"放大成"现在还在猛涨"的错觉。

**结论（写入研究库防后人重走）**：
- ❌ 加重近期权重 = 放大滞后，非治滞后
- ❌ 缩短窗口 = 对异常暴涨更敏感、噪声更大、丢趋势市利润
- ❌ 把分钟数据塞进日级 calc_score = 破坏算法语义（slope 变分钟级，年化失真）
- ✅ 滞后不能从算法内部治（加权/短窗/分钟数据都走不通），只能从决策层补救

## 15. 支持证据

## 17. 偏差诊断

**预测 vs 实际不一致点**：
- 预测：7 闸全周期稳定减少卖强买弱。实际：高度市况依赖，牛市/V型赢、震荡输、熊市持平。

- 预测：7 道闸各有贡献。实际：闸5 贡献绝大部分，其余 6 闸价值小。

**可能原因**：
- 动量末端反转（牛市/V型）vs 趋势延续（震荡）是两种相反行情，单一阈值无法兼顾。
- 进攻否决的"今日在跌"误杀 V 型反转的"跌后强反弹"。
- 闸1/3/4/6/7 触发条件与闸5 高度重叠，独立性不足。
