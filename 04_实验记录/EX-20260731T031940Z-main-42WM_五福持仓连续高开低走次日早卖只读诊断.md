## 1. 新手摘要

这次实验想知道：五福当前持仓若连续2至3个完整交易日都“收盘上涨，但上涨主要来自向上跳空，开盘后全天回落”，这种结构是否会延续到次日上午，从而值得提前卖出。

本轮不直接改策略。信号只使用昨日及更早的完整分钟线；固定用次日09:31至09:35的量加权分钟收盘价代表早卖，并与13:10继续持有价格比较。

连续2日是唯一候选，连续3日只做“确认越久应越强”的单调性检查。实际只有11次连续2日信号、1次连续3日信号；连续2日早卖净改善均值`4.848bps`，但中位数`-13.509bps`、胜率仅`27.27%`，连续3日反而为`-1.565bps`。因此固定规则失败，不实现早卖，也不改分钟窗口或阈值。

## 2. 研究背景

当前五福在13:10选择目标并处理旧仓。用户提出，与其只看当日13:10状态，不如在开盘前分析当前持仓过去2至3日的完整分钟路径：如果“高开低走”反复出现，就把它视为可延续的标的内日内结构，次日早盘先卖。

这个假设有三个优点：

- 信号在当日开盘前完全可得，不依赖当天未来分钟。
- 只调整卖出时点，不改候选池、动量排序、市场状态或买入目标。
- “连续出现才跟随”天然提供反过拟合约束，不需要评分或参数网格。

但旧证据给出谨慎先验：FQ6显示同日分钟动量分量没有稳定成交改善；旧双池策略的5日隔夜/日内结构选股最终也未形成组合alpha。本实验不同之处是只研究五福实际持仓的次日上午退出，不把结构用于选股。

## 3. 实验前假设

H1：五福开盘前持仓若连续2个完整交易日均呈现“日涨、向上跳空、开盘至收盘下跌且分钟线斜率为负”，次日09:31至09:35卖出并在13:10重新接回当前流程，应稳定优于一直持有到13:10；连续3日确认的改善不应弱于连续2日。

H0：这种结构没有跨日持续性，或只反映一般早盘时段效应；连续确认不会增强结果，早卖在年度、置换或对称负控中失败。

## 4. 实验前预测

如果假设为真，应该看到：

- 指标：连续2日信号扣除必要额外交易成本后的平均早卖改善至少`10bps`，中位数大于0，正改善率至少55%。
- 交易行为：冻结1583个开盘前持仓日中，可用事件不少于1500；连续2日信号不少于40次并覆盖至少5年，连续3日不少于20次并覆盖至少4年。
- 风险表现：本轮只比较旧仓09:31至13:10价格路径，不把价格改善代理写成组合收益或回撤改善。
- 分段表现：连续2日信号有事件年份中，至少80%年份均值为正且至少4年为正，最差年度不低于`-20bps`。
- 确认单调性：连续3日信号的平均改善和正改善率均不得低于连续2日。
- 负控：连续2日信号相对同证券同年份非信号日的改善至少`10bps`且1000次分层置换单侧`p <= 0.05`；对称“连续低开高走但日跌”信号不少于20次，其早卖均值应不大于0，并至少比高开低走信号低`20bps`。

每日结构固定定义，所有价格均乘当日公司行动因子后比较：

```text
完整历史日要求：至少230根有效分钟Bar，且存在09:31开盘与15:00收盘
daily_return = close_d / close_d-1 - 1
gap_return = open_d / close_d-1 - 1
intraday_return = close_d / open_d - 1
minute_slope = OLS(log(minute_close), minute_index)

fade_day:
  daily_return > 0
  gap_return > 0
  intraday_return < 0
  minute_slope < 0

recovery_day:
  daily_return < 0
  gap_return < 0
  intraday_return > 0
  minute_slope > 0
```

事件结果固定为：

```text
early_price = 09:31至09:35分钟close按volume加权
hold_price = 13:10精确分钟close
当日结果要求：09:31至09:35五根分钟Bar齐全、合计volume大于0，且13:10价格精确存在
gross_early_sell_improvement_bps = (early_price / hold_price - 1) * 10000

若13:10仍选择原持仓：
  net_proxy_bps = gross_early_sell_improvement_bps - 4
否则：
  net_proxy_bps = gross_early_sell_improvement_bps
```

`4bps`来自冻结成本的额外一卖一买：每边`1bp`佣金加`1bp`撮合价差。最低佣金和真实下单容量仍须由正式A/B处理。

## 6. 竞争性解释

即使结果符合预期，也可能是：

- 过去连续高开低走可能反映已知的跳空后回落，但次日未必继续，尤其动量ETF会发生修复反弹。
- 早盘普遍高于13:10时，任何随机信号都可能显得有效；因此必须相对同证券同年份非信号日做置换。
- 连续3日是连续2日的嵌套稀疏样本，少数行情可能抬高均值；因此同时要求事件数、胜率和年度广度。
- 09:31至09:35量加权分钟收盘价不是实际订单成交，不能替代完整撮合。
- 13:10可能仍选择原持仓，早卖会增加一卖一买；只读代理先扣4bps，但最低佣金、资金规模和部分成交仍可能扩大成本。

## 7. 证伪条件

出现以下情况，本假设不通过：

- PXLM不精确复现冻结A。
- 可用持仓事件少于1500或分钟覆盖率低于95%。
- `fade2`少于40次或不足5年；`fade3`少于20次或不足4年。
- `fade2`净代理均值低于10bps、中位不为正、胜率低于55%，或年度正向比例/最差年失败。
- `fade3`均值或胜率弱于`fade2`，说明“多确认一天更像规律”的假设不成立。
- 分层置换`p > 0.05`或信号相对非信号日增量低于10bps。
- `recovery2`少于20次、早卖均值为正，或与`fade2`差距不足20bps，说明结果缺少方向特异性。
- 结果依赖事后改为开盘价、09:32、10分钟窗口、只选2日或3日、去掉分钟斜率、年份、ETF或幅度阈值。

任一失败即停止本固定规则，不做正式A/B，不围绕窗口和状态挽救。

## 13. 支持证据

- 冻结基线身份精确通过，1528/1583个持仓日可用，覆盖率96.526%并覆盖7个自然年，数据问题不是失败主因。

## 14. 反对证据

- 连续2日只有11次，连续3日只有1次，远低于预注册的40次与20次，无法支撑稳定规则。

- 唯一连续3日事件净改善`-1.565bps`，同时弱于连续2日均值和胜率，直接反对“保持越久越像规律”。

- 全部可用持仓日若普遍早卖，平均会少`14.168bps`，说明把13:10整体提前也没有支持。

## 15. 偏差诊断

实验前预计连续2日形态应至少出现40次，实际只有11次；定义同时要求日涨、向上跳空、开盘后下跌和全日分钟斜率为负，在五福真实持仓中比肉眼描述严格得多。这个稀疏性是定义本身的客观结果，不能看完后删除条件来扩样本。

即使接受稀疏样本，结果也没有呈现预期的中位、胜率、年度和3日增强。局部均值优势由两次极端日主导，更符合偶然行情而非持仓标的可延续的个体规律。

本轮没有真实早盘订单簿和开盘集合竞价成交，只能使用09:31至09:35分钟收盘量加权代理；但由于方向性、样本数和单调性已在代理层失败，没有必要进入更昂贵的撮合A/B。

## 16. 研究判断

建议状态：`kill`

理由：预注册18项门禁仅冻结身份、可用事件数、数据覆盖、年份覆盖、信号相对对照均值差5项通过；核心信号样本、净改善、中位、胜率、年度、3日增强、置换和对称负控均失败。否决本次固定“连续2至3日高开低走后次日早卖”规则，不进入正式A/B，不修改策略或实盘。
