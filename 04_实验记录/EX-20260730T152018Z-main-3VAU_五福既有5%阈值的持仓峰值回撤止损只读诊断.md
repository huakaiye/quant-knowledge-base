## 1. 新手摘要

当前止损只看“现价是否比买入成本低5%”。如果一只ETF先上涨很多、随后从最高点回吐超过5%，但仍高于成本，当前止损不会行动。

这次不改5%这个已有数字，只问：若从每次持仓建立后的最高价也计算5%回撤，第一次新增触发后继续持有到原卖点，历史上是否通常继续亏？只有答案跨年稳定、覆盖主要回撤段，才值得完整回测。

实际共得到33次新增峰值触发，但假设提前退出相对真实持有平均少赚 `0.689%`，7年中仅2021年均值有利；最大5个回撤段也只有最大回撤段出现1次正贡献。移动止损主要截断了随后恢复的趋势，并没有覆盖连续小亏构成的回撤。

## 2. 研究背景

冻结基线启用 `fixed_stop_loss_threshold=0.95`，2020-2026共1583个持仓观察日只触发14次。最大回撤发生在2025-02-21至2025-04-07，回撤18.92%，期间没有一次成本止损，损失分散在多个ETF和多次换仓。

全局波动率缩仓虽然降低3.17个百分点回撤，却损失67.91个百分点CAGR；换仓延迟和旧仓豁免又连续被证伪。因此下一条应针对成本止损没有覆盖的“盈利回吐”，而不是继续调仓位或选择阈值。

## 3. 实验前假设

H1：用现有5%阈值增加“持仓建立后从峰值回撤5%”退出，可以捕捉一批成本止损尚未触发、随后仍继续下跌的会话；该现象至少50次、覆盖6年，并在主要回撤段中重复出现。

H0：峰值触发太少，或触发后多数会恢复；移动止损会过早截断五福依赖的高波动趋势，不值得正式回测。

## 4. 冻结事件口径

1. 用冻结基线真实成交重建从仓位0变为正、再回到0的持仓会话；数量不平衡或样本末未平仓会话排除并报告。
2. 为避免干扰已有分段买入，峰值跟踪只从该会话最后一笔实际买入成交后开始。
3. 初始峰值取完整持仓的实际加权平均买入价；之后只在现有止损回调真实观察到的分钟窗口内，用当时分钟收盘价更新峰值。
4. 第一次满足 `current_price <= running_peak × 0.95` 的分钟为峰值触发。阈值固定为实盘已有0.95，不测试0.94、0.96、0.97或ATR。
5. 若触发分钟不早于实际退出，或与现有成本止损没有行为差异，不计“新增峰值触发”。
6. 触发价和实际退出价必须存在精确分钟，不用邻近分钟。当前平台价差 `0.0001`、佣金率 `0.0001`、最低5元用于估算假设卖出净额。

主结果定义：

```text
hypothetical_net = 峰值触发分钟按既有卖出价差和佣金全额退出的净额
actual_net = 原会话实际卖出净额
benefit_on_buy_cost = (hypothetical_net - actual_net) / 实际含佣买入成本
continuation_return = actual_net / hypothetical_net - 1
```

`benefit_on_buy_cost > 0` 或 `continuation_return < 0` 表示触发后继续持有到原卖点更差。这只是局部离线反事实；同日禁止重买、后续重新入场和复利路径必须由正式回测决定。

## 5. 实验前预测与硬门

只有全部满足才允许另开一个正式候选：

1. 冻结基线精确复现；可查询的完整会话分钟路径覆盖率不低于95%。
2. 相比成本止损新增的峰值触发不少于50次，覆盖至少6个自然年。
3. `benefit_on_buy_cost` 均值和中位数均大于0，正收益比例至少55%。
4. 至少5个自然年的平均 `benefit_on_buy_cost` 大于0。
5. 删除收益最大的5个、最支持H1的事件后，剩余等权平均仍大于0。
6. 按日权益高水位自然划分所有非重叠水下期，取深度最大的5段；只把峰值日至谷底日（含首尾）发生的新增触发归入该段。至少4段的等权 `benefit_on_buy_cost` 合计为正，且最大回撤段本身合计为正。

若通过，唯一候选是在现有成本5%止损之外增加同阈值的持仓峰值5%止损；目标选择、分段买入、同日禁止重买、固定成本止损及其他执行语义全部保持。零门槛扫描，不同时加冷却期或仓位缩放。

## 7. 竞争性解释与证伪

- 局部卖出反事实没有模拟次日重入；即使通过，也只能进入正式A/B回测，不能直接宣称提高收益。
- 移动止损天然会在高波动趋势中频繁触发，触发后若恢复，可能截断策略核心收益；中位数、事件广度和年度门用于防止只看少数暴跌。
- 主要回撤由连续多次小亏构成，单持仓移动止损可能根本不触发；最大5段门会直接证伪这种错位。
- 实际成交价含滑点，假设触发也按现有价差和佣金扣减；不允许用无成本理想价支撑候选。

第5节任一条件失败即停止，不调整5%、事件起点、回撤段数量或年度门挽救假设。

## 13. 支持证据

- 最大回撤段确有1次新增触发，局部提前退出可多保留约 `0.52%` 的买入成本收益。
- 33次事件中16次提前退出有利，2021年4次事件均值合计方向为正，说明盈利回吐风险真实存在但不广泛。
- 816条路径覆盖完整，分析没有因缺少暴跌分钟而低估触发。

## 14. 反对证据

- 新增事件只有33次，且提前退出收益均值、中位数和胜率全部不通过；总体方向是截断恢复而非减少亏损。
- 删除最有利5次后，平均损失扩大到 `1.2075%`，少数成功止损不能代表机制有效。
- 7年仅2021年平均有利，2020、2022、2023、2024、2025、2026全部为负。
- 最大5个回撤段中，一段完全没有峰值触发，另外三段触发后反而少赚；机制与主要回撤结构明显错位。

## 15. 偏差诊断

实验前预计固定成本止损遗漏了广泛的“先赚后吐”问题；实际主要回撤由跨ETF、跨会话的小亏连续累积，单一持仓很少从峰值回撤5%。发生回撤时，五福高波动趋势又常在原退出前恢复，使移动止损的机会成本超过保护收益。

这不是5%略宽或略窄的问题：主假设在事件广度、年度广度、尾部稳健和最大回撤覆盖四个层面同时失败。改测3%、4%、6%会把机制失败改造成阈值搜索，因此停止。

主要回撤已确认是多会话连续小亏，而非单会话大幅回吐。下一轮直接归因每日组合亏损在“隔夜”和“日内”哪个时段形成；只有同一时段在最大5个回撤段和多年样本中稳定为负，才考虑一个不依赖新阈值的执行候选。
