## 1. 新手摘要

这次实验想知道：在历史回撤期里，如果用"池内最高分 + 合格标的数"两个条件同时触发空仓（而不是只用最高分），能不能既覆盖大部分历史最深回撤，又不误伤反弹日。

预期：单一"最高分<2"在 2022-2023 回撤期会让策略全程空仓，同时误伤反弹。引入"合格数<5"作为第二门槛，能把"真正全市场走弱"和"龙头没站出来但市场广度还在"区分开。

实际：双门槛（规则 C）平均覆盖仅 4.59%，远低于预测的 50%，决策树自动判定场景 C_kill。反直觉根因：A 股 ETF 池里"合格数<5"几乎永远不触发——即使最深回撤期，通过 close>ma20>ma60 的标的平均仍有 27 只（货币/债/避险 ETF 逆势站上均线），导致第二门槛失效，双门槛退化成"几乎不触发"。单一分数门槛（规则 A，最高分<2）反而覆盖 42.70%，但段外误伤 25.19%、反弹误伤 16.67% 偏高。

说明：双门槛方案在 A 股 ETF 池被证伪。合格数这个维度不适用于 ETF 池（与股票池结构性不同）。

但还不能说明：动量强度择时这条路死了。规则 A 显示单一最高分<2 有 42.7% 覆盖率，问题只是误伤偏高，可通过"连续 N 日确认"或换第二门槛改善。

下一步：kill 双门槛（规则 C）。规则 A 值得保留为候选，但需降低误伤——建议下一探针测"连续 3 日最高分<2 才空仓"的防抖动变体，或换第二门槛为"Top3 平均分的 60 日滚动分位"。

## 2. 研究背景

实盘 hard5 只在 score 过高时拒绝标的，没有"过低时空仓"的下限机制。前置诊断（2023-06-19 至 2023-12-21，-27.13% 段内最大回撤）显示：回撤期 126 天 hard5 后池内最高分平均 2.189、单日最低降到 0.016，hard5 几乎不触发；说明回撤期不是 hard5 失灵，而是策略根本没设下限门槛——全市场动量塌陷时仍买"矮子里的高个"。

前置交互已确认"单一分数下限"会把整个回撤期 126 天全部空仓，等于错过随后反弹。需要引入第二个维度（合格标的数）做联合门槛。

## 3. 实验前假设

主假设 H1：在 2020-01-01 至最新交易日全样本，对每个交易日 T 计算：

- max_score(T) = 当日 hard5 过滤后池内最高分
- pool_n(T) = 当日通过 pool filter 后的合格标的数

定义三个候选规则：

- 规则 A：max_score(T)<2 则 T+1 空仓
- 规则 B：pool_n(T)<5 则 T+1 空仓
- 规则 C：max_score(T)<2 且 pool_n(T)<5 则 T+1 空仓

假设规则 C 同时满足"回撤覆盖率高、反弹误伤率低"。

## 4. 实验前预测

覆盖率（历史每段最大回撤窗口的触发日数占比）：

- 规则 A >= 80%
- 规则 B >= 30%
- 规则 C >= 50%（关键阈值）

段外日误伤率：

- 规则 A >= 30%
- 规则 B <= 5%
- 规则 C <= 10%（关键阈值）

反弹日误伤率（反弹日 = 每段最大回撤谷底后 20 个交易日）：

- 规则 C <= 15%

信号稳定性：规则 C 抖动率 <= 20%

四组阈值全部满足 -> 进入正式 EX；规则 C 覆盖率 <30% 或反弹日误伤 >30% -> kill。

## 5. 基准和对照

| 对照 | 用途 |
| --- | --- |
| 实盘 hard5 baseline 净值 | 各段最大回撤窗口定位 |
| platform momentum.py 加权回归 | score 计算单一事实源 |
| 实盘 pool filter | 合格标的数计算 close>ma20>ma60 |
| IRPR 探针 panel 函数 | 复用数据管道 |

关键约束：本探针只计算每日 max_score(T) / pool_n(T) 并应用三个规则的假想信号，**不进行任何回测撮合、不下任何模拟单、不改变任何参数默认值**。

## 6. 竞争性解释

- 样本期偏倚：2020-2026 恰好 4 次显著回撤；未来 blowoff 衰竭模式抓不到。
- 阈值后视偏差：阈值（2, 5）来自主控交互讨论；第 7 节微扰校验。
- 池定义偏倚：合格数萎缩可能是流动性结构副产品。
- 回撤窗口定位偏倚：段内最大回撤由 hard5 baseline 决定。
- 空仓收益假象：只数触发日数，不算空仓真实净值差。

## 7. 证伪条件

出现以下任一项，规则 C 视为不通过：

- 规则 C 在各段最大回撤窗口触发日数占比 <30%
- 规则 C 在反弹日触发频率 >30%
- 规则 C 在段外日触发频率 >20%
- 阈值微扰：max_score in {1.6,2.0,2.4} x pool_n in {4,5,6} 9 组组合，覆盖率/误伤率变化 >30%
- 信号抖动率 >40%
- 任意一段覆盖率为 0%

## 13. 支持证据

1. report.md 决策树自动判定场景 C_kill（规则 C 覆盖 4.59% << 阈值 50%）。
2. 规则 B（合格数<5）单独覆盖仅 4.89%——证明"合格数<5"在 A 股 ETF 池几乎不触发。
3. 前置诊断已确认：2023 回撤期 126 天通过 pool filter 的标的平均 27.3 只，远高于 5 的门槛。
4. 9 组微扰全部极低覆盖（最高 5.79%），证明结论不是阈值偶然，是结构性失效。

## 14. 反对证据

可能反驳"kill 双门槛"的观点：

1. 规则 C 反弹误伤 0.00%、抖动率 2.10%——非常干净，只是覆盖太低。
2. 规则 A（单一最高分<2）覆盖 42.70% 且抖动 8.60% 不高，说明"动量强度择时"本身有信号，问题只在"误伤偏高"。
3. 第二门槛换成非"合格数"维度（如滚动分位、成交额）可能恢复区分度。

## 15. 偏差诊断

| 预测 | 实际 | 原因 |
| --- | --- | --- |
| 规则 C 覆盖 >=50% | 4.59% | 严重高估了"合格数<5"的触发频率。预测假设回撤期市场广度会萎缩到 <5 只标的，实际 A 股 ETF 池有货币/债/避险 ETF 逆势站上均线，合格数始终 >=20。 |
| 规则 A 全程空仓 | 覆盖 42.70% | 上轮交互预测"单一门槛会让 2023 段 126 天全程空仓"，实际只覆盖 42.7%——说明最高分<2 不是全程，只是部分日子。 |

根因：预测阶段没意识到 ETF 池（含货币/债 ETF）与股票池在"市场广度"上的结构性差异。股票池熊市时跌破均线的占绝大多数，合格数会真萎缩；ETF 池永远有几只逆势品种。这是预注册第 6 节"池定义偏倚"的真实化。

## 16. 研究判断

| 场景 | 触发条件 | 主控建议 |
| --- | --- | --- |
| A | 规则 C 覆盖 >=50% 且段外误伤 <=10% 且反弹日误伤 <=15% 且 9 组微扰稳定 | 进入正式 EX |
| B | 规则 C 覆盖 >=30% 但反弹日或段外误伤超阈 | 加第三门槛探针 |
| C | 规则 C 覆盖 <30% | kill |
| D | 微扰下不稳定（>30%） | revise，重做阈值标定 |

**本次判定：场景 C_kill。** 规则 C 平均覆盖 4.59%（<30%），9 组微扰全部极低（1.52%~5.79%），结论稳定。双门槛方案在 A 股 ETF 池结构性失效。

补充判断：规则 A（单一最高分<2）覆盖 42.70% 但段外误伤 25.19%、反弹误伤 16.67% 偏高，不值得直接进正式 EX，但其"动量强度择时"信号有 42.7% 覆盖率值得保留为候选方向。
