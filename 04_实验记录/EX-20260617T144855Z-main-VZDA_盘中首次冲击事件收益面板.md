## 1. 新手摘要

这次实验想知道：朴素“每天 13:09 涨幅榜第一名”已经失败后，如果只看“昨日未热、今天盘中突然冲击、价格仍站稳且同主题有扩散”的 ETF，是否能更早识别还没有太晚的热点。

我们原本预计：如果问题确实出在原事件定义太滞后，那么“首次盘中冲击”事件的 H5 收益应该强于 hard5 proxy、同日随机、同主题随机、前移一日同代码和延迟入场。

实际看到：主事件从 1542 个日历日缩到 `612` 个，H5 均值从 VGMH 朴素 Top1 的 `0.3156%` 提高到 `0.4780%`，略强于 hard5 proxy 的 `0.4600%`，也强于同日随机和同主题随机。但 H5 相对 hard5 中位数仍为 `0`，超额胜率只有 `47.06%`，分段只有 `2/4` 为正，前移一日同代码 H5 均值仍高达 `4.2414%`。

这说明：首次冲击过滤确实减少了一部分随机追高和同主题普涨问题，但没有解决核心滞后性。很多“今日未热、13:09 首次冲击”在统计上仍像是前一交易日同代码强势的后续残余，而不是新的可交易开端。

但还不能说明：即使通过，这也只是只读事件面板，不等于组合回测通过，更不能直接改实盘。

下一步要做：先生成平台只读脚本并运行前台可见命令，再根据负控结果决定 5BNB 是继续收窄、转 rolling LTR/注意力代理，还是新增决策卡 `park`。

## 2. 研究背景

本实验属于 [[02_研究方向/RD-20260613T002916Z-main-5BNB_双池轮动盘中可交易热点事件诊断|5BNB]]。前序 [[04_实验记录/EX-20260613T021659Z-main-VGMH_1309盘中热点事件收益面板预注册|VGMH]] 证伪了每日 13:09 `intraday Top1`：真实事件 H5 平均 `0.3156%`，弱于 hard5 proxy `0.4896%`，且同主题随机和前移一日同代码都能解释主要收益。

这个失败提示“涨幅榜第一”太可能是已经被看见的滞后结果。本轮不扩大 TopN、不后验搜索阈值，而是新开实验，把事件定义改成更靠前的首次冲击：

- 今天 13:09 前已经有足够强的日内冲击。
- 昨天同代码没有进入热榜，也没有明显日内上涨。
- 价格没有明显从盘中高点回落，且站上 13:09 前 VWAP。
- 同主题不是孤立一只上涨，而是 Top10 中至少有多个正涨成员。

本轮只读取 VGMH 已生成的 `candidate_panel_enriched.csv`，不重新查库、不更新数据、不运行组合回测、不修改策略默认逻辑。

## 3. 实验前假设

若 13:09 可交易时点仍存在可利用的注意力扩散或订单压力延续，那么“昨日未热、今日首次盘中冲击且同主题扩散”的 ETF，从 13:10 到 H5 的收益应稳定强于 hard5 proxy 和多个负控；如果收益仍被同主题随机、前移一日或延迟入场复制，说明我们看到时仍然太晚。

## 4. 实验前预测

如果假设为真，应该看到：

- 指标：主事件数不少于 `300`；H5 相对 hard5 的均值、中位数为正，H5 相对 hard5 胜率不低于 `52%`。
- 交易行为：本轮不下单、不撮合，只使用 13:09 信号和 13:10 close proxy 作为最早下一分钟入场标签。
- 风险表现：若首次冲击有效，H1/H3/H5 至少应有一个短周期延续；若只是午后追高，H0/H1 会快速回落，延迟入场和同主题随机会复制收益。
- 分段表现：2020_2021、2022_2023、2024、2025_20260519 四段中，至少 3/4 分段 H5 相对 hard5 均值为正。

固定主事件定义：

```text
full_event_ready = true
ret_prevclose_to_1309_fixed >= 0.02
intraday_rank_1309 <= 5
close_vs_vwap_1309 >= 0
drawdown_from_high_1309 >= -0.01
previous_same_code_missing OR (
  previous_intraday_rank_1309 > 10
  AND previous_ret_prevclose_to_1309_fixed < 0.01
)
theme_top10_positive_count >= 2
```

若同一交易日多个 ETF 满足条件，只取 `ret_prevclose_to_1309_fixed` 最高的一只；若相同，按 `code_jq` 升序固定打破平局。`theme_top10_positive_count` 使用当日 13:09 Top10 中同主题且相对昨收正涨的 ETF 数量。

## 6. 竞争性解释

即使结果符合预期，也可能是：

- 同主题整体上涨导致单标的事件看起来有效。
- 2% 日内涨幅阈值把样本集中在强牛市或特定主题中。
- 前一日未热规则只排除同代码滞后，不能排除同主题已经热。
- 13:10 close proxy 与真实实盘成交价、滑点、容量仍有偏差。
- hard5 proxy 不是完整实盘组合，只是日线默认逻辑的同日候选代理。
- VGMH enriched panel 继承了候选母集和复权对齐边界，本轮不声明完整动态池无未来成分问题。

## 7. 证伪条件

出现以下情况，本假设不通过：

- 主事件数低于 `300`。
- hard5 proxy 覆盖率低于 `95%`。
- `actual_first_shock` 的 H5 相对 hard5 均值或中位数不为正。
- `actual_first_shock` 的 H5 相对 hard5 胜率低于 `52%`。
- H5 相对 hard5 正均值分段少于 `3/4`。
- 同日随机或同主题随机 H5 均值不弱于真实事件。
- 前移一日同代码 H5 均值不弱于真实事件，说明当前定义仍滞后。
- 延迟入场 H5 均值不弱于真实事件，说明 13:10 时点没有独立价值。

## 13. 支持证据

- 相比 VGMH 朴素 Top1，事件数从 `1542` 缩到 `612`，H5 均值从 `0.3156%` 提升到 `0.4780%`。
- 本次真实事件 H5 均值高于 hard5 proxy `0.4600%`、同日随机 `0.2362%`、同主题随机 `0.2583%` 和延迟入场 `0.2763%`。
- H0/H1/H3/H5 均值呈递增，说明这组过滤确实捕捉到部分日内延续，而不只是 H0 立即反转。

## 14. 反对证据

- H5 相对 hard5 均值只高 `0.0180%`，中位数为 `0`，超额胜率只有 `47.06%`，没有达到预注册门槛。
- 分段不稳：2024 和 2025_20260519 的 H5 相对 hard5 均值为负，只有 `2/4` 分段为正。
- 前移一日同代码仍显著更强，H5 均值 `4.2414%`、中位数 `3.5879%`、胜率 `74.93%`。这直接指向滞后性未解决。
- 随机同日 H5 胜率 `54.79%` 高于真实事件 `51.80%`，说明真实事件虽有均值优势，但稳定性不足。

## 15. 偏差诊断

实验前预测要求 H5 超额中位数为正、超额胜率不低于 `52%`、至少 `3/4` 分段正、并打赢前移一日同代码。实际只打赢随机、同主题随机、后移一日和延迟入场；没有打赢 hard5 的稳定性门槛，也没有打赢前移一日。

最可能解释是：`prev_not_hot` 只排除了前一交易日同代码的 13:09 热度，但没排除更早几天或同主题已经热的延续；同时 13:09 的 `2%+Top5+VWAP+near_high` 仍是价格结果变量，不是订单压力源头。它能过滤掉一部分噪声，却仍然不能证明“今天才刚开始”。

## 16. 研究判断

建议状态：`park_candidate`

理由：只读门槛未通过，不应进入交易回测或默认策略。5BNB 若继续，应换成更靠近顶刊机制的拟合方式：同时间段日内延续、订单压力/注意力反转、非线性交互或收缩排序，而不是继续调 13:09 涨幅阈值。
