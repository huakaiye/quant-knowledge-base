## 1. 新手摘要

这次实验想知道：用户先前指定的GPT-5.6 Luna在中等思考强度下，能否正确复核同一批DeepSeek候选，抓住更正公告的证据自足问题和语义对抗样本的否定作用域错误。  
我们原本预计：Luna应在首次调用形成4/4合法结构并抓住四个顶层隔离结论；严格问题码最可能在ANN Item失手，点预测约3/4 gate通过，但正式通过线仍保持4/4。  
实际看到：尚未调用模型。本机OMP支持精确选择器`openai-codex/gpt-5.6-luna`，但连通性探针明确报错`No API key found for openai-codex`。  
这说明：实验契约可以继续准备，但当前只能记为认证前阻断，不能伪造Luna结果，也不能用其他模型替代。  
但还不能说明：Luna能力不足、成本过高或一定优于Flash；模型尚未收到任何正式B2输入。  
下一步要做：生成并校验固定复核包；待用户在OMP完成`openai-codex`登录后，以无格式重试的首次调用执行4个范围。  

## 2. 研究背景

Flash跨文体B2的4个有效结果0/4通过确定性语义门禁，因此事实批准层需要更高智能对照。为隔离“候选质量”和“复核者能力”，本实验不重新生成候选，而是固定复用：

- `DEV-ANN-002`：抽取运行`DEV-PROMPT03-ANN002-20260731T151700Z`；
- `DEV-ADV-003`：抽取运行`DEV-PROMPT03-ADV003-R2-20260731T155000Z`；
- 同一review Prompt v0.3、输入/输出Schema、Item期望、Coverage期望和match hints；
- 模型改为`openai-codex/gpt-5.6-luna`，`thinking=medium`。

两个源运行早于输入锚定加固，只能以显式`legacy_document_snapshot`参加开发对照。该状态不能证明源快照从抽取时起不可篡改。

## 3. 实验前假设

在候选、证据、Prompt、Schema和确定性期望完全固定时，GPT-5.6 Luna中等思考能够同时识别已有条目的关键语义错误与全文关键遗漏，并通过4个B2开发门禁。

## 4. 实验前预测

如果假设为真，应该看到：

点预测与通过线分开：在未见任何Luna输出时，主控预计核心四个顶层结果均为`quarantine`，但ANN Item可能用全文上下文原谅证据不自足，严格gate点预测约3/4。实验假设的正式通过线不因此降低，仍要求下列4/4全部满足。

- 首次结构有效率：4/4；不进行格式重试，不用后续成功覆盖首次失败。
- ANN Item：顶层`quarantine`；6个候选条目判定6/6符合期望，4条问题Claim所需8个问题码全部召回。
- ADV Item：顶层`quarantine`；5个候选条目判定5/5符合期望，c4必须命中`predicate_unsupported + polarity_mismatch`。
- ANN Coverage：候选表示4/5，命中唯一缺失C05，缺失Gold召回1/1。
- ADV Coverage：候选表示1/2，命中唯一缺失C02，缺失Gold召回1/1。
- 四个确定性门禁4/4通过；任何模型自报结果都必须再由本地评分器裁决。
- 完整记录首次调用耗时、token和费用；本轮不预设成本上限，只与Flash同任务数据比较。

## 6. 竞争性解释

即使结果符合预期，也可能是：

- GPT-5.6 Luna已经在训练中见过类似错误模式，不代表开放域事实复核稳定。
- 只有两篇开发文档，且一篇为显式合成夹具，不能代表全部新闻文体。
- Item期望是在Flash输出后建立，虽对Luna输出是预先固定，但不是候选前封存标注。
- review Prompt v0.3针对既知错误开发，可能对同类案例过拟合。
- Luna更强但成本或延迟使全量复核不经济，最终仍需风险路由。

## 7. 证伪条件

出现以下任一情况，本假设不通过：

- 任一正式调用无有效结构；失败留在4次首次调用分母中。
- 任一Item顶层结果、条目verdict或必要问题码不符合绑定期望。
- 任一Coverage未命中唯一缺失Gold，或把已表示Gold误报成遗漏。
- ADV c4仍被接受，或把“不代表已收到”改写成“无人收到”。
- 模型调用工具、搜索、扩展、技能、规则或持久会话。
- 为得到通过结果而修改候选、Prompt、Schema、期望、hints或开启格式重试。

分母边界预先固定：缺key或401/403属于`blocked_auth / not_executed`，不进入模型分母；provider已接受推理后返回格式或契约错误，计模型失败且不重试；无法证明返回模型正是固定selector时记invalid comparison；429、网络或5xx只记transport failure，可整体重新排期一次，但不得选择性保留较好输出。

即使4/4通过，也只形成开发期`L0`证据，不直接采用。候选前封存集和跨文体重复仍是后续门槛。
