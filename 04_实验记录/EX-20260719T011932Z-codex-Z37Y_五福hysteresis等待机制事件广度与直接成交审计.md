## 1. 新手摘要

A478 证明“恢复时先买 25%”缺少可靠触发机制，但不等于 13:10 目标明确下跌时等待也无效。
本实验把两件事彻底拆开：先看等待日是否广泛改善组合，再直接核对 immediate 与 hysteresis
在同一天、同一目标上的真实成交价，判断等待是否真的买得更便宜。

本实验只读取已经落盘的两个正式结果，不运行新回测、不改策略、不查询行情、不搜索新的
斜率阈值或等待时点。

## 2. 研究背景

PC97 按简约优先规则把 hysteresis 列为历史统计赢家。它与 staged 使用相同的 13:10 初始
死区，但首次恢复时直接满仓，不存在 20%/25% 比例问题。现有完整区间终值显示它优于
immediate，但终值不能回答优势是否由少数等待日产生，也不能证明初始跌势越强时等待越有
价值。因此在继续任何随机日程回测前，先完成不增加计算样本的机制审计。

## 3. 实验前假设

当目标在 13:10 的归一化斜率低于 `-0.001%/min` 时，等待至趋势恢复或 14:55，能够在多数
事件中取得更低的真实买入价，并形成广泛而非头部事件驱动的组合改善；初始跌势越强，直接
成交价节省应越大。

## 4. 冻结方法与预测

1. 输入只使用 WVUV 的 `baseline_immediate_cost1.json` 和
   `ablation_hysteresis_cost1.json`。日期必须完全一致为 2020-01-02 至 2026-07-09，
   共 1,578 个交易日。
2. 从 hysteresis 的 `trend_buy.records` 提取每个交易日首条动作为 `wait` 的事件，数量必须
   与既有正式资产一致为 334。事件起点固定为当天 13:10 的目标、`slope_pct` 和
   `signal_price`，不得事后删掉强制买入、下单失败或不利事件。
3. 组合层使用 hysteresis 相对 immediate 的逐日对数收益，把每一天归属到最近一次等待
   事件，窗口从等待日开始，到下一等待日前结束。
4. 组合层门禁：事件累计贡献大于 0；事件中位贡献大于 0；正贡献事件比例大于 50%；移除
   贡献最大的 10 个事件后仍大于 0；7 个自然年至少 5 年累计贡献为正。
5. 直接成交层从两份正式结果的 `execution_audit.trades` 聚合真实 BUY fills。按交易日、目标
   代码和本地成交时点匹配 immediate 的 13:10 后首笔目标买入与 hysteresis 的实际恢复或
   强制买入，使用成交量加权均价计算 `log(immediate_price / hysteresis_price)`。正值表示
   等待后买得更便宜。
6. 所有 334 个等待事件都进入分母。两侧真实成交均匹配的比例必须至少 98%；未匹配事件记为
   非正贡献并单独列出，禁止静默删除。直接成交门禁：匹配事件的中位节省大于 0；以 334 为
   分母的正节省比例大于 50%；移除最大的 10 个直接节省后总和仍大于 0；至少 5/7 年总节省
   为正。
7. 单调性门禁：计算初始 `slope_pct` 与直接成交对数节省的 Spearman 相关。初始斜率越负，
   等待价值应越大，冻结要求 `rho <= -0.10`。固定种子 `20260719011932` 做 10,000 次单侧
   置换，要求 `p <= 0.10`。未匹配事件不进入相关计算，但仍在匹配率和正事件率中受罚。
8. 按自然年、实际买入时点和初始斜率四分位生成描述性分组，不据结果反推新阈值、时点或
   非单调规则。

整体通过要求组合层、直接成交层和单调性门禁全部通过。通过也只把 hysteresis 保留为下一轮
策略级随机负控候选，不自动替换 immediate；任一门禁失败则继续 park，不能调整斜率阈值或
挑年份挽救。

## 6. 竞争性解释

- 完整结果仍来自已观察的 2020-2026 历史，只能形成 L1 证据。
- 两条权益路径的仓位数量会因早期差异产生轻微复利和最低佣金非线性，组合事件贡献不是纯
  成交价差；因此必须与直接成交层同时看。
- 更低成交价可能来自普遍午后回落，而不是斜率规则具备日期判别力；即使本次通过，仍需要
  另立完整随机等待日程负控。
- 真实市场门禁导致的未成交必须保留，不能用理论价格补齐。

## 7. 证伪条件

- 334 个等待事件或日期不能从正式结果精确复核。
- 组合贡献只由少数事件产生，或多数事件、年度广度不支持。
- 等待没有在多数事件中取得更低真实成交价。
- 初始跌势强弱与直接成交节省没有预期负向单调关系。
- 结果需要删除强制买入、失败订单、年份或恢复时点才能成立。

## 11. 实际观察

输入完整性通过：两个正式结果均覆盖 2020-01-02 至 2026-07-09 的 1,578 个交易日，提取
到 334 个 13:10 初始等待事件；immediate 与 hysteresis 的同日同目标真实 BUY fill 完整
匹配 `334/334`，没有用理论价格补齐。

| 组合事件门禁 | 结果 | 判定 |
| --- | ---: | --- |
| 334 事件累计相对收益 | `+24.4098%` | 通过 |
| 事件中位对数贡献 | `-0.00000292` | 失败 |
| 正贡献事件 | `159/334 = 47.60%` | 失败 |
| 移除贡献最大的 10 个事件后 | `+0.2031%` | 通过 |
| 正贡献自然年 | `5/7` | 通过 |

| 直接成交门禁 | 结果 | 判定 |
| --- | ---: | --- |
| 真实成交匹配率 | `100%` | 通过 |
| 成交价节省中位数 | `0` | 失败 |
| 正节省事件 | `138/334 = 41.32%` | 失败 |
| 移除最大的 10 个节省后 | `+0.1277%` | 通过 |
| 正节省自然年 | `5/7` | 通过 |
| 初始斜率与直接节省 Spearman | `+0.0213` | 失败 |
| 10,000 次单侧置换 | `p=0.6539` | 失败 |

年度上，2020 和 2022 的组合相对收益分别为 `-2.0593%`、`-0.3242%`，直接成交价差连乘
分别为 `-1.9493%`、`-0.7286%`。2023、2025 和 2026 的收益较强，但没有形成多数事件优势。

恢复时点的描述性分组揭示了机制错位：13:40 恢复的 133 个事件直接成交价差连乘为
`-32.2922%`，只有 `10.53%` 买得更便宜；14:10 的 82 个事件为 `-0.6138%`；14:40 的
54 个事件为 `+9.6809%`；被迫等到 14:55 的 65 个事件为 `+70.4000%`，其中 `90.77%`
买得更便宜。也就是说，历史优势主要来自持续下跌后等到尾盘，而不是“趋势一恢复就买”的
普遍有效性。

初始斜率四分位没有单调排列：Q1 至 Q4 的直接价差连乘依次为 `+6.4577%`、`+9.1564%`、
`+0.9400%`、`+7.2199%`。不能据此从已观察分组中挑选新阈值。

## 12. 研究判断

当前状态：`diagnostic_failed_hysteresis_mechanism / completed`。

冻结的 hysteresis 机制没有通过组合事件广度、直接成交多数性和初始斜率单调性门禁。终值
相对 immediate 的 `+24.4098%` 是真实历史结果，334/334 成交匹配也排除了归因缺失，但
典型事件不占优，且初始跌势强弱不能解释等待价值。因此不进入策略级随机等待日程回测，
不升级为生产、实盘或默认候选。

本实验没有证明“尾盘等待”必然无效。14:55 分组很强，13:40 恢复组反而明显不利，说明
原设计把两种不同机制混在一起：持续下跌时减少暴露可能有效，恢复即追入则可能付出更高
价格。但该分组结论来自事后观察，不能直接改成“统一等到尾盘”或新的恢复时点规则。

staged 比例家族和 hysteresis 均继续 `park`，生产基线仍为 `immediate + stop 5%`。若继续
研究，必须先提出不依赖本次分组挑选的新经济机制，并使用封闭时间块或预注册错位负控控制
既有数据上的过拟合。

完整机器可读结果见 `summary.json`，人读摘要见 `report.md`。本实验没有运行新回测、查询新
行情、改动交易逻辑或依据结果调整阈值。
