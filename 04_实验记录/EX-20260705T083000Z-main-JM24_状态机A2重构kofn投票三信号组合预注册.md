## 1. 新手摘要

- **这次实验想知道**:把 v21 实盘的 A2 三关空仓信号换成"k-of-n 投票的状态机",能不能在 2015 牛顶崩盘时提前空仓防御。
- **我们原本预计**:状态机替换第三关(反应式 slope)能让 2015 回撤从 -22.6% 改善到优于 -15%。
- **实际看到**:**状态机替换第三关(replace_slope)在 2015 完全不生效**,结果与 baseline 逐位一致;完全替换三关(replace_full)虽生效但默认参数让回撤恶化 0.72pp、收益降 5.49pp。
- **这说明**:原假设错了——**2015 牛顶零防御的根因不是第三关 slope 滞后,而是第一关分数阈值**。2015 牛市 ETF 动量分数普遍远高于 2.0,所以"分数<2.0 AND 广度<0.5 AND 趋势破位"整个 AND 链路在崩盘初期就被第一关卡死,第三关换成任何领先信号都没用。
- **但还不能说明**:状态机信号本身是否有 alpha(只测了默认参数 replace_full);OR 逻辑(任一关触发即空仓)是否能解决短路问题。
- **下一步要做**:EX-JM25 改 AND 为 OR——状态机作为独立"严重市场信号"绕过分数关,任一严重即空仓。证伪条件是 2025 V 型误报。

## 2. 研究背景

### 2.1 病灶

v21 的 A2 三关空仓条件（见 [[04_实验记录/EX-20260628T120000Z-main-D3_raw_closes缓存累加污染根因定论|EX-D3]] §13.2）：

```text
A2 触发 = (score < 2.0) AND (breadth < 0.5) AND (hs300_close < hs300_ma200) AND (hs300_ma200 20日斜率 < 0)
```

第三关的 `ma200 20日斜率<0` 是**反应式滞后**条件：2015 杠杆牛崩盘时，200 日线斜率在见顶（2015-06-12）后仍维持正值长达 **214 天**（[[04_实验记录/EX-20260629T145619Z-main-FXF4_A2基准标的风格错配只读诊断|EX-FXF4]] §12.3），首次转负要到 2016-01-15。

后果（[[04_实验记录/EX-20260628T120000Z-main-D3_raw_closes缓存累加污染根因定论|EX-D3]] §13.2）：

- **2015 全年 A2 空仓天数 = 0 天**
- V21 在 2015 = V20 = 原 baseline（三关完全不触发）：收益 +44.74%、回撤 -22.60%（[[04_实验记录/EX-20260704T055055Z-main-V21BS_V21基准确认V20加gap0.3协同有效|EX-V21BS]] §8.3）

### 2.2 已 park 方向的失败模式（必须避开）

| 失败模式 | 已撞墙方向 | 本实验如何避开 |
| --- | --- | --- |
| #1 "领先另一滞后指标"≠"领先市场见顶" | FXF4 换基准、JA43 死叉领先 slope | S1 是价格位置（领先见顶本身），不依赖另一滞后指标 |
| #2 组合层 alpha≈0，事件级有效被负控复制 | S2T4/JA43/CJC9/M3VC/2XKW/8AB7/A29 | **错位一日负控是硬门禁**，复制率 > 50% 直接 park |
| #3 时段依赖（2025 强趋势误伤） | MCYG/CS dispersion/RA5 | **2025 V 型不误报是硬条件** + k≥2 投票容错 |

### 2.3 为什么现在做

[[04_实验记录/EX-20260629T152523Z-main-NBWM_A2反应式滞后量化与预警信号候选筛选|EX-NBWM]] 阶段 0.4 已筛出 L3（距 ma200<-3%）为唯一未 park 候选，[[04_实验记录/EX-20260704T055055Z-main-V21BS_V21基准确认V20加gap0.3协同有效|EX-V21BS]] §14 第 4 条也明确"仅剩 L3 备选，需独立研究"。但 L3 仅有 L1_只读诊断证据，无任何 formal 回测、无组合层负控、无样本外验证。

本实验是把 L3 单独验证扩展为**三信号 k-of-n 状态机**，原因：单信号容易撞失败模式 #2，组合投票可同时治理误报与漏报（[[04_实验记录/EX-20260629T234912Z-main-JA43_L2死叉预警信号组合层formal与负控|EX-JA43]] §16.4 已提到"死叉 AND slope近0"可过滤 4/6 误报，但未验证）。

## 3. 实验前假设

**H1**：用三个互补领先信号（S1 价格位置 / S2 斜率缓冲带 / S3 死叉∧slope近0）的 k-of-n 投票（k≥2）替换 A2 第三关，能在样本内（2015-2021）将 2015 牛顶回撤从 -22.60% 改善到 ≥ -15%，且在样本外（2022-2026）不退化、2025 V 型段不误报。

**H0（零假设，证伪目标）**：状态机的改善幅度，在错位一日负控下能被复制 ≥ 50%（即信号无组合层 alpha，撞失败模式 #2）。

本次**只验证** H1 的样本内可达成性 + H0 是否被否定。

## 6. 竞争性解释

即使结果符合 H1 预测，也可能是因为：

- **C1 组合层 alpha≈0，事件级有效被错位负控复制**（最可能）：S2T4 +0.08% 超额 = 信号 +0.50% − 随机 +0.42% 几乎为零；本实验状态机改善若 < 错位版改善 × 2，即撞此模式
- **C2 三信号共线性高**：S1/S2/S3 都依赖 ma200，可能 k-of-n 实际等价于单信号；消融会暴露（去掉任一信号后无变化）
- **C3 参数过拟合**：thr_L3 / thr_slope / thr_slope_near0 / k 四参数在样本内调优；邻域 CV > 10% 即撞此
- **C4 A2 在 2015 不触发反而保护反弹**：状态机提前空仓会错过 2015-09 后的反弹，可能 2015 收益大降但回撤只略改善
- **C5 数据基础设施 bug 污染结论**：raw_closes 累加污染曾造成 RA5/A2 四次定性反转（[[04_实验记录/EX-20260628T120000Z-main-D3_raw_closes缓存累加污染根因定论|EX-D3]]）

## 8. 状态机信号定义（预注册，扫描前冻结）

### 8.1 三个信号

```python
# S1: L3 距均线（来自 EX-NBWM 唯一活信号）
S1 = (hs300_close - hs300_ma200) / hs300_ma200 < thr_L3

# S2: 斜率缓冲带（来自 EX-FXF4 阶段1.2 空白）
#     捕捉"涨势衰减但未转负"的过渡区间：EX-FXF4 显示 hs300 见顶当日
#     slope=+0.3951%/日（强正），到 2015-09-30 降到 +0.0728%（接近 0 未破）。
#     缓冲带识别"slope 已从高位回落但仍为正"——比纯反应式"转负"提前。
S2 = (0 < hs300_ma200_20日斜率) AND (hs300_ma200_20日斜率 < thr_slope)

# S3: 死叉 AND slope近0（来自 EX-JA43 §16.4 备选）
S3 = (hs300_ma60 < hs300_ma200) AND (hs300_ma200_20日斜率 < thr_slope_near0)
```

### 8.2 k-of-n 投票

```python
triggered_count = sum([S1, S2, S3])
state_machine_fires = (triggered_count >= k)
# 触发后动作：全切防御 ETF 511880.SH（与 A2 一致，二元空仓）
```

### 14.1 Smoke 阶段(已完成)

| 状态机触发 | - | 否(正确) | **是(生效)** | **否(短路)** |

### 14.2 关键诊断发现

**发现 1：replace_slope 模式在 2015 牛顶完全不生效**

`replace_slope` 默认参数(L3=-3%, k=2)在 2015 单年跑出与 baseline **逐位一致**的结果(145880.63 / 200 笔)。根因:

```python
# etf_dual_pool_r010b_action_ablation.py:6770
is_low = is_low and sm_result["is_triggered"]
```

`is_low` 在此处已是"分数<2.0 AND 广度<0.5"的结果。2015 牛顶期间 ETF 池内动量分数普遍 **>>2.0**(25 天加权回归对前期涨幅有记忆),所以 `is_low` 始终为 `False`,Python 的 `and` 短路求值使状态机结果被忽略。

**这推翻了 EX-JM24 §3 的核心假设 H1**:原以为"用状态机替换第三关(反应式 slope)能提前防御 2015 牛顶",但**真正的瓶颈是第一关(分数阈值),不是第三关(slope 滞后)**。即便第三关换成完美的领先信号,只要分数<2.0 不满足,三关整体就不会触发。

**发现 2：replace_full 模式生效但默认参数净负向**

`replace_full`(完全绕过三关,只看状态机)在 2015 触发了(成交 200→161 证明提前空仓),但默认参数(L3=-3%, k=2)净负向:
- 回撤从 -21.82% **恶化**到 -22.54%(+0.72pp)
- 收益从 +45.88% 降到 +40.39%(-5.49pp)

说明状态机触发时机不对——可能过早空仓错过 7-9 月反弹,或过晚空仓未防住 6-8 月主跌。

### 14.3 部分网格结果(进行中)

135 组合 grid 主要扫描 `replace_full` 模式(因 replace_slope 已证短路)。运行中 6 段并发,已完成约 10 段(部分结果待汇总)。但基于发现 1,即便全量完成也只能在 replace_full 框架内优化,无法解决根本问题。

## 15. 支持证据

- **证据 A(baseline 管道正确)**:EX-JM24 baseline(disabled)与真实 v20 config(`v20_real_baseline_11yr.json`)在 2015 单年跑出**逐位一致**的 145880.63 / 200 笔,证明 `action_ablation.py` 与 `hldr_variant.py` 逻辑等价,且状态机扩展点(disabled 模式)对 baseline 零影响。
- **证据 B(replace_full 状态机生效)**:replace_full 默认参数跑出 140391.50 / 161 笔,与 baseline 差异显著(收益 -5.49pp、成交 -39 笔),证明状态机机制本身已连通并改变交易行为。
- **证据 C(replace_slope 短路)**:replace_slope 跑出与 baseline 逐位一致的结果,结合代码 `is_low = is_low and sm_result["is_triggered"]` 的短路语义,确证状态机结果被忽略。
- **证据 D(根因是分数阈值)**:历史记录 [[04_实验记录/EX-20260628T120000Z-main-D3_raw_closes缓存累加污染根因定论|EX-D3]] §13.2 明确"2015 全年 A2 空仓天数=0",而该文档未区分是哪一关导致——本实验首次定位到**第一关(分数<2.0)是瓶颈**。

## 16. 反对证据

- **反对 1**:replace_full 默认参数净负向,可能只是参数不好,不代表 replace_full 框架本身无效。135 组合扫描可能在某个参数组合找到正收益点。
- **反对 2**:replace_slope 的短路问题可以通过改变 AND 逻辑解决(例如改为 OR,或分数阈值在状态机触发时动态降低),不一定推翻整个方向。
- **反对 3**:仅跑了 2015 单年,未跑全周期,可能其他年份(2018/2022)表现不同。

## 17. 偏差诊断

实验前预测(§4.1)与实际结果对比:

| 预测 | 实际 | 偏差根因 |
| --- | --- | --- |
| 2015 回撤改善至 [-18%, -12%] | replace_full -22.54%(恶化) | 状态机触发时机错——L3=-3% 在 hs300 跌破 ma200 三个百分点时触发,但此时往往已是下跌中段,错过反弹 |
| 2015 空仓天数 30~80 天 | replace_full 成交减少 39 笔(约 20 个换仓日) | 部分对齐,但空仓时点与最优不一致 |
| 错位负控复制率 < 50% | 未跑(因主假设已证伪) | - |

**核心偏差**:实验前假设"第三关 slope 滞后是 2015 牛顶零防御的根因",但诊断发现**第一关分数阈值才是瓶颈**。这是对问题本质的重新认识——[[04_实验记录/EX-20260629T145619Z-main-FXF4_A2基准标的风格错配只读诊断|EX-FXF4]] 量化的"214 天 slope 滞后"是真实存在的,但它只是"三关整体不触发"的**三个原因之一**,且不是最严格的那个(分数<2.0 在牛顶崩盘初期更难满足)。

## 18. 研究判断

**建议状态:`revise`**

**理由**:

1. **核心假设 H1 被证伪**:状态机替换第三关(replace_slope)在 2015 牛顶完全不生效,因为第一关分数阈值先短路了。原假设"反应式 slope 滞后是 2015 零防御根因"不准确——**根因是三关的 AND 逻辑在牛顶崩盘时被最严格的关(分数)卡死**。

2. **状态机机制本身有效但用法需重构**:`replace_full` 证明状态机能触发并改变交易行为,但"完全绕过分数+广度两关"过于激进,且单独的状态机信号(价格位置+斜率缓冲带+死叉)在 2015 时机不够精准。

3. **不 kill 的理由**:状态机模块(`state_machine_leading_signal.py`)代码可用、测试 9/9 PASS、importlib 集成稳定、135 config 已生成。这些资产可服务于**重新设计后的方向**。

4. **不 park 的理由**:park 意味着"暂不做",但本实验已产生明确的研究价值——**排除了"第三关 slope 滞后是根因"的假设,定位到真正的瓶颈是三关 AND 逻辑**。这是 revise(需重新设计)而非 park(暂停)。

## 19. 下一步

基于发现 1(分数阈值短路)和发现 2(replace_full 净负向),下一轮最值得做的实验是:

**EX-JM25(新预注册):状态机作为"或门"而非"与门"——分数/广度/状态机任一触发即空仓**

核心改动:
```python
# 原逻辑(AND,三关全满足)
is_low = (score < 2.0) and (breadth < 0.5) and (hs300_below_ma or sm_triggered)

# 新逻辑(OR + 分级,任一严重信号即空仓)
severe_market_signal = sm_triggered  # 状态机:领先市场信号
low_score = score < 2.0              # 个股层疲软
is_low = severe_market_signal or (low_score and breadth < 0.5)
```

这能让状态机在 2015 牛顶(市场崩盘但个股分数仍高)独立触发空仓,同时保留分数+广度作为"个股层确认"。

证伪条件:OR 逻辑导致 2025 V 型段或 2018/2022 震荡市误报(状态机独立触发但市场快速恢复)。
