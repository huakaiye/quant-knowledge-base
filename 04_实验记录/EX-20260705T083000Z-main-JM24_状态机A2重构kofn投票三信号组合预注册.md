## 2. 研究背景

### 2.1 病灶

v21 的 A2 三关空仓条件（见 [[04_实验记录/EX-20260628T120000Z-main-D3_raw_closes缓存累加污染根因定论|EX-D3]] §13.2）：

```text
A2 触发 = (score < 2.0) AND (breadth < 0.5) AND (hs300_close < hs300_ma200) AND (hs300_ma200 20日斜率 < 0)
```

第三关的 `ma200 20日斜率<0` 是**反应式滞后**条件：2015 杠杆牛崩盘时，200 日线斜率在见顶（2015-06-12）后仍维持正值长达 **214 天**（[[04_实验记录/EX-20260629T145619Z-main-FXF4_A2基准标的风格错配只读诊断|EX-FXF4]] §12.3），首次转负要到 2016-01-15。

后果（[[04_实验记录/EX-20260628T120000Z-main-D3_raw_closes缓存累加污染根因定论|EX-D3]] §13.2）：

- **2015 全年 A2 空仓天数 = 0 天**
- V21 在 2015 = V20 = 原 baseline（三关完全不触发）：收益 +44.74%、回撤 -22.60%（[[04_实验记录/EX-20260704T055055Z-main-V21BS_V21基准确认V20加gap0.3协同有效|EX-V21BS]] §8.3）

### 2.2 已 park 方向的失败模式（必须避开）

### 2.3 为什么现在做

[[04_实验记录/EX-20260629T152523Z-main-NBWM_A2反应式滞后量化与预警信号候选筛选|EX-NBWM]] 阶段 0.4 已筛出 L3（距 ma200<-3%）为唯一未 park 候选，[[04_实验记录/EX-20260704T055055Z-main-V21BS_V21基准确认V20加gap0.3协同有效|EX-V21BS]] §14 第 4 条也明确"仅剩 L3 备选，需独立研究"。但 L3 仅有 L1_只读诊断证据，无任何 formal 回测、无组合层负控、无样本外验证。

本实验是把 L3 单独验证扩展为**三信号 k-of-n 状态机**，原因：单信号容易撞失败模式 #2，组合投票可同时治理误报与漏报（[[04_实验记录/EX-20260629T234912Z-main-JA43_L2死叉预警信号组合层formal与负控|EX-JA43]] §16.4 已提到"死叉 AND slope近0"可过滤 4/6 误报，但未验证）。

## 3. 实验前假设

**H1**：用三个互补领先信号（S1 价格位置 / S2 斜率缓冲带 / S3 死叉∧slope近0）的 k-of-n 投票（k≥2）替换 A2 第三关，能在样本内（2015-2021）将 2015 牛顶回撤从 -22.60% 改善到 ≥ -15%，且在样本外（2022-2026）不退化、2025 V 型段不误报。

**H0（零假设，证伪目标）**：状态机的改善幅度，在错位一日负控下能被复制 ≥ 50%（即信号无组合层 alpha，撞失败模式 #2）。

本次**只验证** H1 的样本内可达成性 + H0 是否被否定。

## 6. 竞争性解释

即使结果符合 H1 预测，也可能是因为：

- **C1 组合层 alpha≈0，事件级有效被错位负控复制**（最可能）：S2T4 +0.08% 超额 = 信号 +0.50% − 随机 +0.42% 几乎为零；本实验状态机改善若 < 错位版改善 × 2，即撞此模式
- **C2 三信号共线性高**：S1/S2/S3 都依赖 ma200，可能 k-of-n 实际等价于单信号；消融会暴露（去掉任一信号后无变化）
- **C3 参数过拟合**：thr_L3 / thr_slope / thr_slope_near0 / k 四参数在样本内调优；邻域 CV > 10% 即撞此
- **C4 A2 在 2015 不触发反而保护反弹**：状态机提前空仓会错过 2015-09 后的反弹，可能 2015 收益大降但回撤只略改善
- **C5 数据基础设施 bug 污染结论**：raw_closes 累加污染曾造成 RA5/A2 四次定性反转（[[04_实验记录/EX-20260628T120000Z-main-D3_raw_closes缓存累加污染根因定论|EX-D3]]）

## 8. 状态机信号定义（预注册，扫描前冻结）

### 8.1 三个信号

```python
# S1: L3 距均线（来自 EX-NBWM 唯一活信号）
S1 = (hs300_close - hs300_ma200) / hs300_ma200 < thr_L3

# S2: 斜率缓冲带（来自 EX-FXF4 阶段1.2 空白）
#     捕捉"涨势衰减但未转负"的过渡区间：EX-FXF4 显示 hs300 见顶当日
#     slope=+0.3951%/日（强正），到 2015-09-30 降到 +0.0728%（接近 0 未破）。
#     缓冲带识别"slope 已从高位回落但仍为正"——比纯反应式"转负"提前。
S2 = (0 < hs300_ma200_20日斜率) AND (hs300_ma200_20日斜率 < thr_slope)

# S3: 死叉 AND slope近0（来自 EX-JA43 §16.4 备选）
S3 = (hs300_ma60 < hs300_ma200) AND (hs300_ma200_20日斜率 < thr_slope_near0)
```

### 8.2 k-of-n 投票

```python
triggered_count = sum([S1, S2, S3])
state_machine_fires = (triggered_count >= k)
# 触发后动作：全切防御 ETF 511880.SH（与 A2 一致，二元空仓）
```
