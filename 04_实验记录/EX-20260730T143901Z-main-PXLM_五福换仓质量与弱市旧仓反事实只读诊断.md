## 1. 新手摘要

这次实验想知道：五福在正常市场允许“旧仓分数只要达到第一名的90%就继续持有”，但进入A股走弱期后会把这个缓冲关闭，旧仓必须恰好是第一名才能留下。这个不对称是否造成了弱市中的低质量换仓？

我们原本预计：若弱市关闭旧仓保留确实有害，那么那些“旧仓仍在第一名90%以内、却因弱市规则被换掉”的交易，换入目标在实际持有期内应当普遍跑输继续持有旧仓，并且下行路径更差。

实际看到：完整2020至2026历史只有9次落入这个精确区间，远少于预注册要求的30次；而且方向与假设相反，实际换入目标平均比旧仓多赚 `2.35` 个百分点，中位数也略为正，目标下行路径更差的比例只有 `33.33%`。

这说明：弱市关闭旧仓保留不是当前主要回撤来源，现有强制切换在这9次事件中反而总体有效。不能把正常期0.9旧仓保留机械搬到弱市。

但还不能说明：即使只读诊断通过，也不能证明改规则后整个组合一定提高收益并降低回撤；路径变化、后续选标和交易成本必须由下一份独立预注册的完整回测验证。

下一步要做：维持弱市 `ratio=1.0`，不扫描90%附近参数；利用已经获得的759次换仓审计，转向覆盖面更大的隔日反转/换仓摩擦诊断。

## 2. 研究背景

当前冻结实盘基线为 `staged20 + recheck20 + both_up_delay5 + stop5%`。前序波动率仓位实验说明，统一缩仓虽能降低回撤，却会长期牺牲大部分收益；最大回撤期又由多个ETF和多次换仓共同构成。因此下一步应先检查“换仓本身是否在特定状态下系统性变差”，而不是再叠一层普遍降仓。

五福目标选择代码存在一个现成但不对称的机制：

```text
正常期：candidate_ratio = score_threshold_ratio = 0.9
走弱期：candidate_ratio = 1.0
```

持仓数为1时，正常期旧仓只要通过过滤、进入Top10且分数不低于Top1的90%，就优先保留；走弱期则只有旧仓等于Top1才保留。历史OFAT虽然扫描过 `score_threshold_ratio`，但走弱期始终被代码覆盖为 `1.0`，所以没有单独检验这条非对称分支。

本实验只做诊断，不产生交易候选。它不修改目标选择、订单、仓位、止损或实盘代码。

## 3. 实验前假设

H1：在A股走弱期，旧仓仍处于正常期90%保留区间时强制切换到Top1，是一类广泛而非少数极端事件驱动的低质量换仓；按实际新目标持有区间比较，新目标的终点收益和区间最差收益均弱于继续持有旧仓。

H0：弱市强制换仓是有效的风险切换，或者样本太少、结果由极少数事件主导；这时不得把正常期的0.9旧仓保留直接搬到弱市。

## 4. 冻结事件定义与实验前预测

### 4.1 唯一可行动事件

一个 `weak_retention_zone` 事件必须同时满足：

1. 13:10只读选标快照的 `market_state=weak`。
2. 当时恰有一个旧仓，最终目标恰有一个，且两者不同。
3. 旧仓通过走弱期当日实际启用的全部过滤并位于过滤后Top10。
4. `old_score >= top1_score * 0.9` 且 `old_score < top1_score`。
5. 当日订单确实使旧仓持仓从正数归零、不同的新目标从零转为正数；没有实际换仓的信号只报告，不进入收益统计。

`0.9` 是实盘已有正常期值，不搜索 `0.85/0.92/0.95`，不按结果改变边界。弱市中低于90%的换仓仅作为未受候选影响的描述性对照，不用来另造规则。

### 4.2 唯一反事实口径

- 事件起点：新目标本次持仓会话的第一笔实际买入成交分钟。
- 事件终点：该新目标持仓会话下一次从正数归零的最后一笔卖出成交分钟。
- 对目标和旧仓均读取起止分钟及区间内的原始分钟收盘价；两者必须在起止分钟都有精确记录，否则整条事件排除并报告原因，不向前后寻找替代分钟。
- `终点收益 = 终点分钟收盘 / 起点分钟收盘 - 1`。
- `区间最差收益 = min(区间分钟收盘 / 起点分钟收盘 - 1)`。
- 主比较为 `目标 - 旧仓`。负值表示本次换仓不如继续持有旧仓。
- 主门只用未扣费的同口径价格收益，避免把假设的省费收益算成机制优势；实际佣金和滑点只作附加说明，下一轮完整回测才计入组合结果。
- 分段买入和后续加仓不改变起点；本口径只评价选标，不冒充真实组合盈亏归因。

### 4.3 允许继续到候选回测的全部条件

只有以下条件全部成立，才允许另建一个“弱市沿用现有0.9旧仓保留”的单机制候选：

1. 可比 `weak_retention_zone` 事件不少于30个，覆盖不少于4个自然年，价格完整率不低于95%。
2. `目标终点收益 - 旧仓终点收益` 的中位数小于0，目标跑赢旧仓的事件比例小于50%。
3. 按自然年统计的事件平均超额，在至少4个自然年为负。
4. 删除对假设最有利的5个最差换仓事件后，剩余事件等权平均超额仍小于0；同时完整样本等权平均超额小于0。
5. `目标区间最差收益 - 旧仓区间最差收益` 的中位数小于0，且目标下行路径更差的事件比例大于50%。
6. 只读审计扩展后的冻结基线与既有artifact逐日权益最大绝对误差不超过0.005元，订单、成交、持仓、趋势、双涨延迟和止损记录完全一致。

这些条件只决定“是否值得跑下一轮”，不决定部署。未满足任一项就停止该分支，不缩小样本、不换持有期、不增加过滤器。

## 6. 竞争性解释

即使H1表面成立，也可能是：

- 事件终点由实际新目标持仓路径决定；若继续持有旧仓，后续决策路径本来会变化，单事件反事实不能代替完整回测。
- 走弱期会切换到全球池，旧仓可能退出当日可交易池；价格能计算不等于实盘一定应继续持有。
- 目标与旧仓可能代表不同市场时区或风险暴露，单纯价格超额没有覆盖隔夜风险和组合现金路径。
- 少数年份、少数ETF或极端事件可能主导均值，因此必须同时检查中位数、事件胜率、年度广度和去除最有利5事件后的结果。
- 旧仓数据缺失或停牌可能选择性排除坏事件，因此必须报告全部排除项和价格完整率。

## 7. 证伪条件

以下任一项出现，H1不通过，本分支直接 `park`：

1. 只读审计改变冻结基线的任何订单/成交/状态记录，或逐日权益对账失败。
2. 可比事件少于30个、覆盖少于4年，或价格完整率低于95%。
3. 目标相对旧仓的终点收益中位数不为负，或目标跑赢比例不低于50%。
4. 负超额自然年少于4个，或删除最有利5个坏换仓后等权平均超额不再为负。
5. 目标相对旧仓的区间最差收益没有更差的广度。
6. 结果需要事后增加分数阈值、固定持有天数、ETF名单或其他条件才能成立。

- 实际换入目标平均超额 `+2.35pp`，删除最支持原假设的5条负事件后反而升至 `+6.16pp`。
- 目标区间最差收益相对旧仓的中位差为 `+0.28pp`，目标下行更差仅3/9，既没有收益证据，也没有风险证据支持保留旧仓。

## 14. 反对证据

- 只有9条事件、3个年份，未达到预注册最低样本量；不能据此宣称 `ratio=1.0` 在所有未来弱市都最优。
- 全部历史已被多轮查看，本轮最多是L1历史诊断。
- 事件终点仍由实际目标持仓路径决定，不能替代完整反事实策略回测；但因为前置诊断已经方向相反，没有理由再消耗回测预算。

## 15. 偏差诊断

实验前预计弱市强制切换会让目标普遍跑输旧仓。实际不仅样本稀少，而且平均收益、事件胜率、年度均值和下行路径全部朝相反方向。原假设不是“差一点通过”，而是机制方向错误。

出现9条而不是更多的原因也清楚：312次弱市换仓中，大多数旧仓已经离开弱市全球池、未通过弱市过滤、跌出Top10或分数低于90%，真正只由 `1.0` 与 `0.9` 差异造成的换仓很少。扫描更宽阈值会把一个明确失败的问题改造成事后参数搜索，因此禁止继续。

## 16. 研究判断

建议状态：`park`

理由：5项机制门只有基线复现门通过；样本门失败且全部方向性指标反对H1。维持弱市 `ratio=1.0`，不建立“弱市沿用0.9”的候选回测。
