## 1. 新手摘要

五福代码已经在每天09:00监控“组合距离历史最高权益是否回撤3%”，但现在只写日志，不影响交易。前几轮证明最大回撤不是某一道换仓过滤器，也不是单只ETF跌5%或从峰值回吐5%，而是多个持仓连续小亏。

本实验只把现有3%告警变成一次最小动作：每个水下期第一次从3%以下穿到3%以上时，当天13:10目标临时改为策略已有的货币基金 `511880`；只防御这一个交易周期，同一水下期不重复，下一日恢复原策略。

不新增阈值，不测试2%、4%、连续多日防御或半仓。目标是完整回测验证它能否在少量风险加速点保住收益，而不是长期留现金。

## 2. 研究背景

冻结基线2020-2026 CAGR为125.87%、最大回撤18.92%。统一波动率缩仓把回撤降3.17个百分点，却损失67.91个百分点CAGR；移动止损又只新增33次触发，平均少赚0.689%，且仅覆盖1/5主要回撤段。

最大5个回撤段均由跨会话连续亏损形成。已有 `drawdown_threshold=0.03`、组合高水位监控和防御ETF，但告警后没有动作。复用这组既有资产、只响应首次穿越，可避免永久防御和新参数网格。

## 3. 实验前假设

H1：组合首次跌破3%说明新的水下期已形成，下一交易周期继续承担满仓动量风险的收益风险比偏低；只防御一天可跳过一部分亏损加速，随后恢复正常，因而全周期收益不降且最大回撤至少改善1个百分点。

H0：3%穿越只是高波动趋势的正常波动；一日防御随机错过反弹并增加交易成本，不能同时提高收益和降低回撤。

## 4. 冻结候选语义

候选只增加布尔开关 `enable_drawdown_first_cross_defense`，默认关闭：

1. 09:00沿用现有 `max_portfolio_value` 与 `drawdown_threshold=0.03` 计算组合回撤。
2. 若前一监控日低于3%、当前首次不低于3%，登记一次向下穿越并把当前交易日标记为防御日。
3. 当前日13:10仍完整计算原始排名，但锁定交易目标时改为既有防御ETF `511880.XSHG`；卖出、趋势分段买入、涨停检查、费用和固定成本5%止损全部沿用。
4. 防御只持续当前交易日；下一交易日恢复正常排名。只要组合晨间回撤仍不低于3%，同一水下期不再次触发；回到3%以内后才允许下一次首次穿越。
5. 防御ETF不可交易时不强行下单，保持原目标并记录失败；不得改为空仓补救。
6. 禁止同时修改3%、防御周期、仓位比例、止损或选标参数。

## 5. 实验前预测与正式硬门

先跑短期smoke证明行为，再跑2020-01-02至2026-07-17连续全周期A/B：

| 组别 | 语义 |
| --- | --- |
| A | 当前实盘冻结基线，研究开关关闭 |
| B | 仅开启首次3%穿越的一日防御 |

B必须全部满足：

1. A与冻结artifact的1584个权益日、期末权益、订单和既有策略指标精确一致；开关关闭时不得新增输出字段破坏基线。
2. B的CAGR严格高于A，最大回撤至少缩窄1.0个百分点，期末权益和Calmar均高于A。
3. B至少产生20次实际防御覆盖，分布在至少6个自然年；防御太少不得用偶然改善晋级。
4. 七个自然年切片中，B回撤不高于A至少5年，收益不低于A至少4年；任何一年收益落后不得超过5个百分点。
5. 按A冻结的最大5个峰值至谷底日期窗口比较同期收益，B至少4段优于A，且最大回撤窗口必须优于A。
6. 前五门全部通过后才运行双倍成本A/B；cost2x下B仍须CAGR高于A且最大回撤至少改善1.0个百分点。

任一主门失败即正式失败，不改阈值、持续天数或触发重置方式。

## 7. 竞争性解释与证伪

- 组合3%回撤是策略自身路径变量，不是外部市场状态；高收益策略常在小回撤后快速反弹，一日防御可能系统性买不到反弹。
- B的回撤路径会改变后续穿越时点，因此必须完整事件驱动回测，不能把基准历史事件简单删除。
- 511880收益低但稳定，回撤改善可能只是多一天现金暴露；所以收益必须严格提高，不能接受“少赚换低回撤”。
- 首次穿越可能集中在单一年份；事件数、年份、年度切片和固定五段同时约束偶然性。

任一第5节硬门失败即证伪H1，直接停止。不得把“差一点”解释为继续扫描2%、4%、两日防御或重复触发。

## 12. 实际观察

| 指标 | A冻结基线 | B首次穿越一日防御 | B相对A |
| --- | ---: | ---: | ---: |
| 期末权益 | 20,588,839.57 | 15,678,345.03 | -4,910,494.54 |
| CAGR | 125.87% | 116.66% | -9.22个百分点 |
| 最大回撤 | 18.92% | 19.99% | 恶化1.07个百分点 |
| Calmar | 6.65 | 5.83 | -0.82 |

- B共记录70次首次穿越，70次应用防御目标，其中61次真实改变原目标，覆盖2020至2026全部7年；事件广度门通过。
- 七个自然年收益全部低于A，年度回撤仅4/7年不差于A；2021、2023、2024、2025的收益分别落后约5.33、5.38、16.42、20.00个百分点，年度门失败。
- 冻结最大5回撤段中，B改善第1、3、5段，但恶化第2、4段，只达到3/5，低于4/5硬门。B新的全局最大回撤变为2021-04-30至2021-08-03的19.99%。
- 主门结果：基线行为复现通过；事件广度通过；全周期表现、年度稳定性、冻结回撤段均失败。正式结论为 `reject`。

## 13. 支持证据

- 机制确实改变了61次交易目标并覆盖7年，不存在“开关没有生效”或“仅靠少数年份”的解释。
- 冻结最大回撤窗口2025-02-21至2025-04-07改善约0.47个百分点，2020年第三大回撤改善约3.39个百分点，说明一次性防御在个别路径上有真实保护作用。
- A的逐日权益、期末权益、配置和全部既有策略指标完全一致，A/B差异可以归因于候选开关。

## 14. 反对证据

- B期末权益少491.05万元，CAGR低9.22个百分点，收益提高硬门直接失败。
- B最大回撤没有收窄，反而扩大1.07个百分点；Calmar同步下降，不能解释为“少赚换来更稳”。
- 七年收益0/7不差于A，且四个年份落后超过5个百分点；负面结果跨年稳定。
- 五大回撤段仅3/5改善，2021年第二大回撤恶化1.95个百分点，2026年第四大回撤恶化0.25个百分点。

## 15. 偏差诊断

- 回测引擎在开盘后的首个可用分钟执行晨间监控，审计时间为09:31，而预注册文字沿用实盘代码的09:00。信号仍早于13:10且只读当时权益，没有未来数据；该差异如实保留，不改变失败结论。
- A包装层记录914,018根bar，冻结artifact为914,022根；股票集合相同、交易与权益完全相同。汇总同时保留 `raw_wrapper_exact=false` 与 `behavioral_exact=true`，没有隐藏差异。
- 全历史已经被此前研究污染；本轮没有阈值搜索，失败后也没有追加2%、4%、两日防御或重复触发。
- B自身路径改变后会改变下一次穿越时点，因此采用完整事件驱动回测，没有用A事件做静态删减。

## 16. 研究判断

建议状态：`kill`。

首次3%组合回撤不是可靠的短期避险时点。它既包含后续下跌，也大量位于反弹前；统一切入一天货币基金会稳定错过策略的高弹性恢复，最终收益和风险同时恶化。该机制不进入实盘候选，不再围绕阈值、天数或仓位做参数扫描。

## 17. 下一步

保持实盘冻结逻辑不变。下一轮回到A的真实亏损路径，把最大回撤和全部持仓会话拆成隔夜、开盘后至13:10、13:10后至收盘三段，先判断跨年稳定的损失究竟发生在哪个可交易时段，再决定是否存在一个不依赖回撤阈值的最小候选。
