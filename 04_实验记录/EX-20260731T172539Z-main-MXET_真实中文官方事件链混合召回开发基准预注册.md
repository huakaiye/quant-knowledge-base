## 1. 新手摘要

这次实验想知道：面对后来出现的中文官方事件 A，智库能否在不偷看未来、不靠人工事件族 ID 提示答案的前提下，找回数周到数月前真正相关的事件 B。  
我们原本预计：纯时间倒序会被近期同词材料干扰；中文 text-only 词项基线应明显好于纯新近性，自动结构化增强只能作为独立赛道，不能冒充主结果。  
实际看到：10条事件链、81篇官方文档、30条查询和187条裁决经独立复核后冻结；BM25的`Recall@5=0.950`、`Recall@10=0.989`、`MRR@10=0.817`、`nDCG@10=0.836`，全部主门槛通过，且相对纯时间排序的`Recall@5`提升`+0.744`。  
这说明：在这个非盲中文官方开发集上，简单而可审计的词法召回足以承担第一层历史候选检索，不能再把“最近新闻”当作长期记忆；字符n-gram可作并行候选，而当前结构权重会被同机构、同文种困难负例误导。  
但还不能说明：本实验是已看过部分来源标题后的非盲开发集，不是封存样本外，也不直接证明能正确预测事件 C。  
下一步要做：把BM25接入候选长期记忆工程入口，保留字符n-gram对照；另建按事件族隔离的未见封存集和真实持续采集时间轴，再评估向量与关系重排。  

## 2. 研究背景

本实验属于 `RD-20260731T090245Z-main-KLCN`，承接固定夹具实验 `EX-20260731T165756Z-main-L6RP`。前一轮已经证明追加审计、`known_at` 截止和状态隔离能工作，但只有一个人工事件族，规范实体 ID 几乎直接给出答案。现有18篇抽取语料只有一条中文原文/解读来源链，全部实际首次采集时间集中在约18秒内，不能据此声称验证了“数月长期记忆”。因此本轮建立真实中文官方纵向开发基准，把工程正确性和召回质量分开验证。

污染声明：本预注册发生在汽车以旧换新部分来源标题和摘要已经被主控看到之后，属于 `post-source-discovery / pre-corpus-freeze` 非盲开发实验。它只能用于发现缺陷和冻结下一版方案，不得当作封存集或生产能力证据。

## 3. 实验前假设

在至少10个彼此隔离的中文官方事件族、30个 A-query 上，冻结的 text-only 中文召回器能够比纯新近性更稳定地找回时间上已公开且关系可核验的历史事件节点，同时保持零未来泄漏、零自召回和零 Gold 字段泄漏。

## 4. 实验前预测

如果假设为真，应该看到：

- 指标：宏平均去重 `Recall@5 >= 0.80`、`Recall@10 >= 0.90`、`MRR@10 >= 0.60`、graded `nDCG@10 >= 0.75`；至少24/30个 query 的强正例进入 Top 5。
- 召回行为：text-only BM25/中文词项基线的 `Recall@5` 应比 recency-only 至少高10个百分点；同一信息单元的转载或重复 Claim 不得重复贡献收益。
- 风险表现：未来节点、自身文档、同文复述、Gold 标识泄漏均为0；任一出现即整次运行无效，而不是仅扣分。
- 分段表现：90至365天历史正例 `Recall@10 >= 0.80`；hard negative 占 Top 1 的比例不得超过20%，且应单列同实体错事件、同词错对象、同文体错事件和同源转载。

## 5. 基准和对照

| 对照 | 用途 | 路径 |
| --- | --- | --- |

## 6. 竞争性解释

即使结果符合预期，也可能是：

- 官方页面在本轮才被采集，历史发布日期不等于本系统当时真实看见；因此“回放可用时间”和“实际采集时间”必须分字段报告。
- 查询与正例可能通过公文文号、被修订文件全名或精确数字形成简单匹配，而非真正语义关联。
- 手工选择的10个事件族可能偏向关系清晰、资料完整的政策链，不能代表开放世界新闻分布。
- BM25胜出可能只是中文同词复用，而非实体消歧或因果理解。
- 上游候选抽取漏掉正例时，retriever-conditional 指标仍可能好看，所以必须同时报告端到端分母。

## 7. 证伪条件

出现以下情况，本假设不通过：

- 任一候选的 `actual_known_at` 或 `created_at` 晚于实际查询截止却进入 observed-ingest 结果。
- retrospective 赛道把 `published_at` 伪装成系统真实 `known_at`，或未显式标注其反事实回放属性。
- query 输入或检索特征包含 `chain_id`、`event_family_id`、`source_parent_url`、正例 ID、相关等级、hard-negative 类型或 Gold 摘要。
- A 自身、A 的同文 Claim、同一信息单元的转载副本被当作独立历史正例。
- 少于10个事件族、30个 query，或每个 query 少于3个预先冻结的 hard negative。
- text-only 宏平均去重 `Recall@5 < 0.80`、`Recall@10 < 0.90`、`MRR@10 < 0.60`，或未比 recency-only 的 `Recall@5` 高至少10个百分点。
- 任一未来节点进入正式排名；任一未冻结 qrels 或运行后改标仍进入汇总。

负控或错位检查：

- 每个 query 添加至少一个 `public_available_at > query_as_of` 的未来节点探针，探针永不参与普通 hard-negative 计分，命中即作废。
- 在构建索引快照时显式排除 A 自身及相同 `information_unit_id` 的同文复述。
- 建立 exact-ID/citation-masked 查询变体；主赛道使用去除前序公文全名、文号和正例专有 ID 的文本。

## 14. 反对证据

- 已看过汽车以旧换新部分标题和摘要，因此不是盲评。
- 现有语料在本轮集中采集，真实`observed_ingest`时间无法支持数月驻留；数月指标只属于历史公开时间回放。
- BM25的Top1 hard negative为30%，高于实验前20%点预测；公司公告、同产品地方细则和同机构材料仍会抢在正例前面。
- 当前自动结构混合`Recall@5=0.794`，低于BM25 15.6个百分点；发布者、签发者和文种的粗粒度重合会放大“同机构错事件”。
- Gold链诊断也低于BM25，因为同一chain中同时包含正例、转载、派生解释和困难负例；这证明“已知同链”仍不等于“已知关系方向”。
- 事件族由开发者选取，政策链占比高，不能外推社交媒体、跨语言、突发事件或开放世界实体消歧。

## 15. 偏差诊断

BM25失败主要集中在两类：一是公司公告中“同文种、同时间、不同公司”的更正公告，二是中央/地方或同机构内对象相邻的政策材料。字符n-gram减少了部分首位困难负例，但没有改善Recall上限。自动结构混合最严重的失败是北京电动自行车查询：同为北京市商务局、同为地方实施细则的北京家电材料得到完整机构和文种加分，真正的中央前序被挤出Top10。

本轮没有回改冻结参数、查询或qrels。结构增强需要在新实验中改成“先用BM25召回，再以辖区、规范实体、关系方向和来源派生状态重排”，不能直接继续调整本轮0.45/0.25权重。所谓`oracle_structured`应改称“Gold链ID诊断”，下一版如要构造上界，必须使用关系裁决而非仅使用chain ID。

## 16. 研究判断

建议状态：`promote_candidate`

理由：主假设在非盲开发集上通过，BM25可以升级为候选长期记忆的第一层召回基线，字符n-gram作为并行候选；当前结构混合不得升级。由于Top1困难负例点预测失败、数据非盲且没有真实长期驻留，本结论仍是`L2-development`，不开放事实批准、自动推断C或交易动作。
