## 1. 新手摘要

这次实验想知道：10:00已经形成的信息能否识别“旧仓继续暴露到13:10不划算”的日子。
我们原本预计：如果10:00按原策略同一套池、评分、过滤和持仓保留规则计算出的暂定目标已经不是旧仓，那么10:01先卖、13:10再按原策略买新目标或买回旧仓，应该优于一直持有。
实际看到：1074个暂定释放信号中有1054个可比较，4bps净改善均值`-10.127bps`、中位`-4bps`、胜率`46.11%`；即使不计新增成本也为`-6.127bps`。
这说明：13:10的精调价值不能用同一套公式简单提前到10:00。10:00只有30分钟累计量，暂定排名会过度淘汰旧仓；无论下午换新标的还是买回旧仓，主释放规则平均都更差。
但还不能说明：任何未来数据源都不能管理上午旧仓，只能说明当前价格、成交量和同源排名这条历史路线失败。
下一步要做：冻结13:10和实盘逻辑，不做完整A/B，不扫描10:00量比或保留阈值；如继续早卖研究，只能另建独立点时数据方向。

## 2. 研究背景

X6LP发现，10:00冻结池中位数与旧仓共同为负的S3有方向性，但4bps净均值只有`+5.861bps`、胜率`51.72%`，没有达到动作门。E8NR进一步发现，S3中原策略13:10实际退出组平均改善`+13.229bps`，13:10仍选择旧仓组为`-4.791bps`；但“最终是否退出”只能事后解释，不能回填为10:00信号。

用户随后指出：13:10仍选择旧仓不等于10:01卖出一定错误。如果旧仓在这三小时继续下跌，13:10低价买回同样是有效避跌。因此本实验把研究目标从“预测下午是否换仓”修正为“判断10:01至13:10是否值得继续持有旧仓”。

本轮不再扩展S3、大盘宽基、分钟窗口或价格形态，只检验原策略本身在10:00的点时暂定目标是否具有经济区分力。

## 3. 实验前假设

主假设H1：仅使用截至10:00可得信息，按原策略同源规则得到的`provisional_target_1000`若不等于开盘前真实旧仓，则10:01释放旧仓、13:10按原策略买入当日正式目标的净改善为正，且优于`provisional_target_1000`仍为旧仓的对照日。

零假设H0：10:00暂定目标只是早盘噪声；释放组随后反弹或成本抵消价差，不能稳定优于继续持有组。

固定互斥原因分类如下，全部报告，不从中事后挑选赢家：

| 分类 | 点时定义 | 是否进入主释放规则 |
| --- | --- | --- |
| `OLD_OUTSIDE_ACTIVE_POOL` | 旧仓不在当日09:40已冻结活动池，且10:00完整暂定目标不是旧仓 | 是 |
| `OLD_FAILED_HARD_FILTER` | 旧仓在活动池，但未通过当前市场状态下原策略启用的硬过滤 | 是 |
| `OLD_BELOW_RETENTION_ZONE` | 旧仓通过过滤，但正常期低于第一名分数的90%，或走弱期不是第一名 | 是 |
| `OTHER_PROVISIONAL_RELEASE` | 无有效排名目标、转入其他防御目标或其他原策略既有分支，使完整暂定目标不是旧仓 | 是 |
| `OLD_RETAINED_RANKING` | 旧仓经排名保留，完整暂定目标仍为旧仓 | 否，对照 |
| `OLD_RETAINED_DEFENSIVE_FALLBACK` | 排名无目标但原策略防御回退仍选择同一旧仓 | 否，对照 |
| `INPUT_INCOMPLETE` | 任一必需点时输入不完整 | 不评价，不得补用晚于10:00的数据 |

主规则只有一个：`provisional_release_1000 = provisional_target_1000 != old_holding`。原因分类只解释机制，单独分类即使历史漂亮也不得在本实验升级成新规则。

## 4. 实验前预测

如果H1成立，主释放规则应同时满足：

- 样本：至少100个可比信号、至少6个信号年份，输入覆盖率与结果价格覆盖率均不低于95%。
- 经济改善：相对原策略处理路径，4bps净改善均值至少10bps、中位数大于0、正改善率至少55%。
- 对照增量：释放组相对暂定保留组的4bps均值至少高10bps；证券乘年份分层置换1000次，单侧`p <= 0.05`。
- 年度广度：至少5个信号年份的4bps均值为正，不依赖单一ETF或单一年份。
- 尾部稳健：删除5个最有利事件后，4bps净均值仍大于0。
- 成本：固定报告0、4、8bps，主判定使用4bps；不得选择最有利成本口径。
- 结果分支：正式目标改变时与原策略旧仓实际处理价比较；正式目标仍为旧仓时，以13:10点时价格回补。两类都按经济改善计量，不把目标身份直接当成成败。
- 风险表现：本轮只读诊断不声称改善CAGR或最大回撤；只有全部门通过才允许另建完整连续A/B。

统一反事实口径：

```text

执行代理 = 10:01分钟open卖出旧仓

若原策略当日实际退出旧仓：参考价 = 原策略旧仓实际卖出均价

若正式目标已改变但旧仓当日因交易约束未退出：标为不可比，不虚构成交

毛改善bps = (10:01卖出代理价 / 参考价 - 1) * 10000
净改善bps = 毛改善bps - 固定增量成本bps
```

## 6. 竞争性解释

即使结果符合预期，也可能是：

- 10:00时点来自2026年6月至7月问题复盘，不是真正未见参数。
- 原策略评分主要使用日线，10:00与13:10暂定目标高度相关，但收益改善只来自少数尾部事件。
- 10:00只有30分钟累计量，投影量比比13:10更噪，可能制造大量假过滤失败。
- 10:01分钟open和13:10分钟close只是可复现代理，未表达排队、冲击、最低佣金和整手回补。
- 同一旧仓卖出后回补会增加真实换手，即使点时价差为正，也可能在完整撮合中消失。
- 历史已被多轮观察，本轮最高只能形成L1只读证据。

## 7. 证伪条件

出现以下任一情况，H1不通过：

- 10:00排名读取任何晚于10:00的价格、成交量、最终目标或当天收盘信息。
- J8TU与W4BY身份门、冻结池身份、公司行为前收、点时历史或输入覆盖门失败。
- 主释放规则未同时通过第4节的样本、经济改善、对照、年度、尾部和置换门。
- 需要改变10:00、10:01、原策略过滤阈值、0.9/1.0保留比例、池构成、市场状态或ETF/年份范围才能通过。
- 只有某个事后原因分类、实际退出组或实际继续持有组有效，而主规则失败。

## 14. 反对证据

- 主规则在均值、中位、胜率、年度、尾部、对照增量和置换七类动作门同时失败。
- 2020至2026只有2021年均值为正；2025至2026近期274例均值`-15.595bps`。
- 旧仓硬过滤失败是最大组且7/7年均值为负，说明10:00同源硬过滤不能作为早卖依据。
- 即使下午原策略实际退出，暂定释放组仍平均`-12.158bps`；预测换仓本身不能解决卖出时机。
- 池外组均值依赖最有利5次，胜率仅41.27%，不能因均值过门而忽略稳定性失败。

## 15. 偏差诊断

实验前预计同源暂定目标比S3更贴近13:10真实决策，可能提高早卖区分力。实际主规则不仅没有改善，反而与保留对照几乎相同且略差。

最大偏差来自成交量：原策略13:10使用约130分钟累计量投影，10:00只有30分钟。将同一量比阈值提前并不是“提前获得下午判断”，而是把一个尚未稳定的估计当成正式过滤，造成1074/1591天被暂定释放。这个结果支持保留13:10，而不是继续微调10:00量比阈值。

## 16. 研究判断

建议状态：`kill`

理由：单一预注册主规则全面失败。10:00同源暂定排名不进入完整连续A/B、策略默认逻辑或实盘；固定原因分类只保留诊断证据，不从池外组事后挑选规则。结论进入[[05_研究决策/DEC-20260804T005035Z-main-KMNL_五福10点同源暂定排名不作为旧仓早卖信号|DEC-KMNL]]。
