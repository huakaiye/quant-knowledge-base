## 1. 新手摘要

这次实验想知道：固定的低成本模型能否在完全不使用工具、不重试的单次调用中，把一篇此前未交给模型的真实中国政府网正文转换为可逐字复核的候选结构。  
我们原本预计：运行只产生一个供应商请求、零工具调用、零格式重试；原始回答必须直接是一个JSON对象，所有证据偏移都能在冻结正文中逐字回读。  
实际看到：尚未执行。真实正文、候选包和准备配置已经离线复验，但预注册、独立放行和单次用户授权仍未全部满足。  
这说明：样本和工程入口已经具备，尚不能说明模型能正确抽取。  
但还不能说明：官方来源中的每个表述都是真实有效的事实，也不能说明模型具有生产稳定性、法律判断、因果判断、投资判断或无人值守入库能力。  
下一步要做：先完成独立的新协议实现、负控、全库门禁和独立放行；用户审阅冻结计划并签发最长一小时、绑定精确工件的单次授权后，才允许唯一模型调用。

## 2. 研究背景

本实验属于个人智库消息面结构化与长期记忆方向，是首次从真实持续采集链进入低成本候选抽取的受控实验。C13和C14只使用合成材料；本实验禁止把其合成执行许可或结果直接复用于真实正文。

冻结目标为当前v3候选包`ICDPI3-21690BA932D1B6E771FC`，包哈希`sha256:62446b8e577c5da79e18a8baf7e851dd73006b3de676db50e4e3cdfb62d84ac6`，配置`ICDPP3-LOCAL-20260810T084607Z`及其哈希`sha256:c11cecb236384a9ca8dd33ce9c21cadc3f6089d25c357ef36d03ffa0fafdeeb3`。包中只有一篇中国政府网正文《集成电路布图设计保护条例》，文档ID为`DOC-910bbdcc6b6e87bac36adffdcd6406dc8cdd955c8f3b999f08bca1f76ee3eafe`；规范化对象为`hot://intelligence/document_objects/v3/normalized/sha256/00/00afbe5214d2a8452bc069291c6bd71f5a0b3c803273d61d73263513401738ff`，哈希`sha256:00afbe5214d2a8452bc069291c6bd71f5a0b3c803273d61d73263513401738ff`，UTF-8正文6604个Unicode code point、19343字节。

准备配置`IUCERP-LOCAL-20260810T084804Z`及哈希`sha256:f1179468287adf12b6a3f988c92f68190dcc54ed0b02bf75b326834d31c959fe`已确认`unseen_sample_ready=true`，同时保持模型、事实、分析上下文、记忆、数据库、行动和交易权限关闭。

正文于2026-08-03采集，早于本预注册，因此本实验不是“选样前预注册”的正式前瞻样本；它只满足“模型未见”的工程定义。模型、Prompt和正式运行器均未读取正文，Gold也没有创建。结果不得计入正式未见集准确率、不得用于调参，也不得改写为前瞻证据。

## 3. 实验前假设

若以冻结正文、`prompt_v0.3`和`news_extraction.schema.json`构造唯一输入，在隔离环境中固定调用`deepseek/deepseek-v4-flash`、`thinking=high`一次，禁用所有工具、MCP、扩展、技能、规则和会话续写，并对原始输出执行零清理的JSON、Schema、元数据、Unicode证据和权限校验，则至少能够形成一个可审计的成功候选或一个不可重试的明确失败，而不会把格式修复、模型自报或官方来源误当成事实确认。

## 4. 实验前预测

如果假设为真，应该看到：

- 运行主门：一个写一次运行ID、一个OMP进程、一个隔离Session、`provider_request_count=1`、assistant终态恰好1个且`stopReason=stop`。
- 隔离门：工具、MCP、扩展、技能、规则、LSP和外部上下文调用均为0；任何`toolCall`、`toolResult`或工具事件都使运行失败。
- 输入门：候选包、配置、正文对象、Prompt、输出Schema、执行器和适配器哈希必须与冻结计划一致；模型只看到Prompt、固定文档元数据和完整正文，不读取Gold、研究笔记、旧模型输出、数据库或网络。
- 输出门：原始assistant文本去除首尾空白后直接解析为唯一JSON object；不接受Markdown围栏、前后解释、数组、标量、JSON修复或第二次格式调用。
- 结构门：输出通过冻结Schema和跨字段校验；Claim和Relation保持候选身份，不出现`independently_confirms`，不自授予事实、法律、因果、行动或交易权限。
- 证据门：每个证据半开区间都以Unicode code point计算，范围合法，切片与输出中的原文逐字相等；不得用标题、摘要或模型常识替代正文证据。
- 计量门：零格式重试，所有assistant请求usage完整聚合；缺失usage、成本字段缺失或总账单字段超过`0.01`美元都判失败。
- 时限门：模型调用绝对期限900秒，进程总时限960秒；超时只封存失败证据，不重跑本实验。
- 下游门：模型成功最多生成隔离候选制品；`metric_eligible=false`，事实批准、分析上下文、长期记忆、PostgreSQL、行动和交易写入计数全部为0。
- 本实验没有交易行为、收益、风险或分段表现；最高只形成L1工程与单样本观察证据。

## 6. 竞争性解释

即使结果符合预期，也可能是：

- 该条例结构清晰、条款短，单样本成功不代表普通新闻、公告、长规划或语义对抗材料也能成功。
- 模型训练参数中可能包含该公开条例；“运行前未向模型提供”不等于模型从未在训练中见过，因此只能评估受控输入下的抽取表现。
- 正文在预注册前已经采集并被主控查看过元数据，存在工程选样偏差；结果不得升级为正式前瞻或随机holdout结论。
- JSON和证据偏移通过只证明结构自洽，不证明主谓宾、否定作用域、法律效力、时效状态或关系语义正确。
- 官方网站能证明发布来源和页面身份，不能自动确认每个Claim为当前有效事实。
- 单次请求成功可能是偶然格式服从；本实验禁止为了证明稳定性而事后重跑。

## 7. 证伪条件

出现以下任一情况，本假设不通过：

- 计划编译前缺少独立放行收据，或运行前缺少用户绑定精确计划、模型、正文哈希、预算和到期时点的单次授权。
- 发生零次或多于一次供应商请求、出现第二assistant终态、非`stop`终态、工具/MCP/扩展/技能/规则事件或会话续写。
- 输入、候选包、正文、Prompt、Schema、运行器、适配器、模型选择器或授权工件在计划后漂移。
- 原始输出不是唯一JSON object，需要去围栏、提取子串、补逗号、改偏移或再次请求模型。
- 任一证据偏移越界、切片不等、证据不自足，或输出使用`independently_confirms`。
- usage无法覆盖唯一请求、账单字段缺失、成本超过`0.01`美元或超过冻结时限。
- 运行后尝试自动写候选记忆、PostgreSQL、事实层、分析上下文、行动或交易系统。

分层裁决固定为`runtime_failed`、`runtime_passed_output_failed`、`runtime_passed_candidate_failed`或`candidate_succeeded_isolated`。失败后不修改本EX、不替换样本、不更换模型、不改Prompt、不增加重试；若要继续必须另开实验。

在个人智库项目中实现专用真实未见抽取计划、收据、隔离执行器和确定性验证器，先用合成负控完成专项与全库门禁。随后由独立身份只读审计并签发绑定当前Git提交、EX、packet、Prompt、Schema、模型、预算和执行器哈希的放行收据。用户审阅冻结计划并另行签发最长一小时的单次授权后，才执行唯一调用。成功输出仍先进入隔离人工复核，失败则保留原始证据并关闭本实验。
