## 决策结论

`park`

暂停“行业状态机选行业后，再在行业内做个股增强”的实现和回测。当前平台没有可用的本地历史行业成分或行业映射，继续做会把行业归属口径变成事后数据或手工假设，未来函数风险不可控。

## 这个节点是什么

这个节点处理的是个股增强能否继续的问题。2GV8 已经暂停了 ETF 代理池过热降权路线，QKD7 进一步检查当前平台是否能回到“行业内选股”的原问题。结论是：没有数据源，不能实现。

## 相比上一个节点改变了什么

- 上一节点：暂停 ETF 代理池 `final_top`，后续优先补历史行业成分或重新定义行业池。
- 本节点：确认当前平台内没有可用历史行业成分，因此个股增强实现也暂停。
- 保留内容：聚宽行业 API 文档、ClickHouse 成分表结构和脚本门禁结果可作为后续导入方案的设计依据。

## 支持证据

- QKD7 显示 `jq_stock_info` 的 `sw_l1/sw_l2/sw_l3/jq_l1/jq_l2/zjw` 覆盖率均为 0。
- 备份表 `jq_stock_info_backup_dates_20260515` 的同名行业字段覆盖率同样为 0。

- 只有聚宽行业 API 文档可作为参考，不能替代本地历史快照。

## 反对证据

- `index_constituent` 表结构存在，说明平台可承载指数成分数据。
- 聚宽文档提供 `get_industry_stocks(industry_code, date=None)` 和 `get_industries` 等接口，后续仍可能通过数据导入补齐。

## 边界

这个决策不能说明行业内个股增强想法无效，也不能说明聚宽没有行业成分数据。它只说明：当前平台本地数据不足，不能直接进入实现、回测、shadow 或实盘边界。
