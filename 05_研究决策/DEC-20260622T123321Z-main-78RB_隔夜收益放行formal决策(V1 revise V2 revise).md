## 决策结论

`revise`（V2 满仓放行在 2020_2021 段达 +15.2% 超额——所有方案最强单段——但四段稳健性仍不够，需时段条件化）

## 这个节点是什么

本决策处理"隔夜收益日内主导信号接进策略后，V1(cap70) 和 V2(完全放行满仓) 两个版本的组合层 formal 表现"。V1 修复全池聚合 bug 后 2/4 段赢（参数矩阵 thr=-0.50 达 3/4）。V2 完全放行在 2020_2021 段 +15.2%（最强单段超额），但 2022/2025 仍输，1/4 段赢。退出机制诊断确认 5-7 分 + 10 天 + 日内主导满仓是最优事件级配置。

## 相比上一个节点改变了什么

- EX-7TJU 只读面板 low 桶全门禁通过（promote_candidate）→ V1 formal 修复 bug 后 2/4 → 参数矩阵 -0.50 达 3/4 → V2 完全放行 1/4（但 2020_2021 +15.2% 最强）
- 从 cap70 限制仓位 → 完全放行满仓：2020_2021 从 +5.6% 提升到 +15.2%（满仓效果显著）
- 退出机制诊断：5-7 分、10 天、日内主导、满仓是最优配置（均值 +5.33%、胜率 71.4%）

## 子代理依据来源

## 支持证据

- **V2 满仓放行 2020_2021 段 +15.2%**（259282 vs hard5 225080）——所有方案最强单段超额，且 MDD 改善（-19.1% vs -20.7%）
- **满仓比 cap70 显著更强**：2020_2021 段 V2=259282 vs V1=237722（+21560），满仓放行效果远好于限仓
- **退出机制诊断**：5-7 分 + 10 天 + 日内主导 + 满仓，均值 +5.33%、中位 +5.64%、胜率 71.4%（28 事件）
- **事件级全门禁通过**（EX-7TJU）：H10 +0.0434、胜率 61.7%、分段 6/7、错位不反转
- **cand≠ref 通过**（0.95 差异）——gate 有极强独立信息量

## 反对证据

- **V2 仅 1/4 段赢**：2022_2023 -2.2%、2024 -0.9%、2025 -7.9%。四段稳健性不够。
- **2022/2025 仍输**：与之前所有方案（CS dispersion/veto）相同的时段依赖问题——信号在某些时段含义不同。
- **分数退出不可行**（95% 非单调）、**成交量退出不可行**（ETF 无拐点）——退出机制选择受限。

## 边界

- 不能说明"隔夜收益信号无效"——2020_2021 段 +15.2% 和事件级 71.4% 胜率证明信号方向正确且有经济显著性。
- 不能说明"2022/2025 不可改善"——可能需要时段条件化（只在趋势向上+广度足时启用）。
- V2 满仓放行的 max_score=8（拦 8+ 过热）本身有效，可能独立于 overnight_share 产生价值。

## 后续动作

1. **时段条件化**：只在特定市场状态（如 M10 趋势向上 + 广度 ≥ 阈值）时启用 overnight gate 放行。这可能解决 2022（熊市不该放行）和 2025（反弹可能需要不同处理）。
2. **算全年年化**：如果 V2 的全年年化 > hard5，即使某些段输也可能值得。
3. **分数上限实验**：max_score=8 vs max_score=7 vs max_score=6 的对比（max_score=8 可能独立有效）。
