## 当前研究信念

ETF 全池 13:09 分布形态存在稳定类型，GMM 软聚类可识别；不同状态次日收益分布有显著差异，且差异来自形态信息（alpha）而非昨日 beta；13:09 盘中采样比纯收盘口径有增量信息。承接 EX-REGM（收盘口径雏形），用 13:09 盘中数据 + 两层多维特征重做。

## 可观察预测

- 轮廓系数 ≥ 0.25
- 状态平均停留天数 ≥ 3 天
- 存在至少一对组合状态，其全池等权次日收益均值差 > 0.3%，且错位一日负控差异 < 原差异一半

## 竞争性解释

状态间收益差异可能是 beta 效应（昨日市场延续），用错位一日负控排除。也可能是 13:09 采样与收盘高度相关（无增量），用 score_close 对照排除。聚类结果可能是 GMM 对噪声过拟合，用 bootstrap 稳定率排除。

## 证伪条件

满足任一即 park，记录"ETF 层 13:09 形态无 alpha 增量"：

- 轮廓系数 < 0.25 → 形态无结构
- 错位一日负控差异 ≥ 原差异 80% → beta 伪装
- bootstrap 聚类中心稳定率 < 70% → 聚类不可复现
