## 一句话说明

建设一套能把新闻、公告和人物表态拆成可追溯事实，并能在未来事件发生时唤醒相关历史证据的个人智库基础设施。

- 所属策略：无；它服务于金融研究和更广泛的个人决策，不直接产生交易指令。
- 所属模块：来源注册、文档归档、Claim 与事件结构化、长期记忆检索、模型路由和分析推断。

- 执行项目：`${THINKTANK_PROJECT_ROOT}` 已建立独立 Git 仓库；本机通过 `tools/Get-ThinkTankProjectRoot.ps1` 解析。原始新闻、模型原始输出和大型评测结果不进入本研究库。

## 当前研究信念

如果先把来源身份、原文证据、人物角色、Claim、事件阶段和知识时间结构化，低成本模型就可能稳定承担大部分重复提取工作；高智能模型只需处理冲突、关联、因果与预测，从而显著降低长期运行成本。

这个信念包含两个不可混淆的部分：

1. 低成本模型只生成带原文证据的候选结构，不直接修改最终事实状态。
2. 长期记忆不是简单向量相似搜索，而是全文、向量、实体、时间和事件关系的混合召回，再由分析模型判断关联是否成立。

当前开发证据支持把流水线拆成候选抽取、确定性校验、独立语义复核和高智能分析，但不再假设同一个低成本模型可以同时承担候选与批准。B2 `0.1-draft` 已实现来源快照、候选/B1/Prompt/Schema哈希绑定、精确ID覆盖、Item期望评分和Coverage两步评分。跨文体6次B2调用有4次结构有效，4个有效结果却0/4通过语义门禁；ANN Claim仅1/5判对，ANN与ADV的Coverage均漏掉唯一缺失Gold，ADV还重复发生否定作用域偷换。Flash因此保留为候选抽取和低风险分流器，B2主复核必须改由更高智能模型或人工承担并做封存对照。

EX-2KTE进一步验证“候选抽取也不能因为肉眼看起来不错就放宽合同”：唯一合成运行中的围栏对象只读诊断通过Schema、元数据和5条证据偏移，正文提示注入未被执行；但事件流有5个assistant终态，最终文本不是唯一JSON，因此权威失败且不产生候选。一次调用、零重试、失败收据和权限封锁通过；这不证明Flash真实中文新闻能力。OMP事件语义和输出格式调整必须另开合成实验，不得改写本次结果。

长期记忆已完成首个不写事实层的纵向切片：候选记录使用追加哈希日志和`known_at`时间截止，默认`analysis`视图只返回`semantic_reviewed`候选，所有命中固定为`candidate`且`fact_approval=false`。随后在10条隔离中文官方事件链、81篇材料和30条查询上冻结真实开发基准：BM25取得`Recall@5=0.950`、`Recall@10=0.989`、`MRR@10=0.817`、`nDCG@10=0.836`，相对纯时间提升`+0.744`。EX-AHS7又在5个全新事件族上确认BM25的`Recall@10=1.000`，但Top1困难负例率`4/15=26.67%`超过20%上限。EX-4PT7实现独立`verified_metadata_priority_v1`安全骨架；EX-FBLD随后以净化packet和retrieval-only Top-20验证真实输入，发现精确副本去重达13问/13对/3域，但产品与设施规范ID均为0、必需父链仅8/11，于是在qrels加载0次时停止评分。EX-G6KC进一步完成独立实体注册表与角色化提及L1合同：唯一可信精确别名可解析，同名、未来、model候选和绑定漂移安全中性或失败。EX-JE6T现已建立官方源发现、追加账本、不可变来源框、单终态正文抓取和健康报告；候选容量达标，但查询窗为0且无Gold/精度结果。EX-UJ9G现把“一条当前A + 至少一条历史B -> 条件假设C”固定为严格接口：每条C必须双侧引用、给出未来时间窗与证伪条件，输出永远不是事实或行动。EX-N29K进一步以单次零重试OMP执行封套绑定显式模型、运行参数、输入、Prompt、Schema、事件、stderr、原文和C2收据；失败留证但不生成分析。EX-LAH3把完整C2分析锁入追加哈希账本，限制最多3条且不得选择性截断，并以到期裁决、修订链、时点回放和最低样本门禁阻断后见之明。EX-6DPX发布独立C3 v2，只从成功执行收据读取和复验全部对象，并保持C3 v1五个冻结文件字节不变。EX-VKK5把v1账本head和静态验证包写一次复制到archive与backup；EX-RX8X又为v2自动冻结账本引用的执行收据、输入、事件、stderr、模型原文、分析和协议快照，删除原hot后仍可从两侧各自重放。EX-J9D3在C4之后建立独立RFC 3161见证层，DigiCert只能作`approved_witness_only`；EX-DVL5把Sectigo固定profile批准为截至2026-11-01的`approved_prospective`候选。HDD为`exFAT`时C4仍只准`provisional_media`，所以C5不会让真实预测越过耐久门禁。当前只批准BM25候选召回、C2结构、C2-E本机执行、C3生命周期与执行来源绑定、C4介质完整性，以及C5的L1时间证据合同；关闭外部运行时上下文不证明模型没有参数先验，不接默认后处理、事实写入、自主决策或正式预测评分。

## 存储与生命周期基线

本方向采用 [[09_术语库/TERM-20260731T093122Z-main-MYZP_冷热分层存储|冷热分层存储]]：SSD/NVMe 热层保存 PostgreSQL、WAL、全文与向量索引、事件关系和历史证据指针；HDD 冷归档层保存原始网页、PDF、图片、音视频和大型可重建输出；备份位于另一块物理介质或另一台设备。

历史原文进入冷层后，其向量、实体、时间、Claim 和稳定归档 URI 仍留在热层。系统先从热层召回相关历史事件，再按需读取机械盘原文，因此既控制容量成本，也不牺牲长期记忆的唤醒速度。

独立智库项目使用 `THINKTANK_HOT_ROOT`、`THINKTANK_ARCHIVE_ROOT` 和 `THINKTANK_BACKUP_ROOT` 三个逻辑根，不在共享资产中写死盘符。当前本机状态为`storage_profile=hybrid / provisional`：热层、HDD归档和独立NVMe备份位于三块不同物理磁盘，当前可信锚的421个对象已从archive和backup分别恢复且内容指纹一致。由于HDD仍为`exFAT`、热层余量低于20%，这只证明候选文件快照可恢复，不能宣称`durable`、PostgreSQL灾备、生产性能或多Agent并发通过。

## 可观察预测

- 在冻结的中文新闻和官方文件测试集上，低成本模型能够稳定输出合法结构，并正确区分记者问题、官方回答、建议、批准、生效、执行、预测和更正。
- 每条关键 Claim 都能定位到原文证据，不依赖模型自行补充事实。
- 规则校验和风险路由能够拦截否定翻转、主体错认、时间或金额错误、虚假多源确认等高风险错误。
- 相比所有文档都调用高智能模型，完整流水线在相同风险上限下可节省至少 60% 总成本，高模型升级比例不超过 30%。
- 当前事件能够通过实体、主题、时间和事件关系召回历史候选，而不是只返回字面相似的旧文章。

## 竞争性解释

- 测试材料太短或太规整，不能代表真实长文、附件、表格和嵌套引用。
- 公开旧新闻可能已被模型记忆，结果并非真正的抽取能力。
- 提示词针对已知错误类型过度定制，在新类型新闻上可能失效。
- 规则校验器承担了主要工作，模型本身并未达到要求。
- Oh My Pi 的固定代理上下文、批处理方式和缓存口径可能掩盖真实生产成本。
- 同一通稿的转载进入不同数据分组，造成事件族泄漏。

## 证伪条件

- 低成本模型出现未被校验器拦截的 P0 致命错误，当前自动入库路线必须 `revise`。
- 关键字段、证据定位或引用归属不能达到预注册门槛，模型只能缩减为分类或候选召回用途。
- 高模型升级率长期超过 30%，或完整成本不能比全高模型方案节省 60%，当前分层路由假设不通过。
- 对抗样本、模型更新或前向样本出现明显性能坍塌，不得把历史测试结论继续外推。
- 如果结构化事件与混合检索不能比单纯关键词或向量检索更好地召回有效历史证据，长期记忆架构必须重新设计。

## 给新手的方向解释

现在我们不仅知道“旧机械盘为什么还不合格”，也有了一套不会自己扩权的搬迁工具：它先列清单，只有你签发与该清单绑定的短期授权才复制，复制后把新旧两边全部重新算一遍；即便成功也只说“副本一致”，不会说“已经切换”或删除旧盘。真实搬迁仍没发生。

新闻很多，但真正有价值的是谁在什么时候、以什么权限、说了什么，以及事情后来是否签署、生效和执行。BM25已经能把强相关历史放进前10名，安全后处理骨架也完成了；旧数据却没有足够的产品和设施规范标签。我们没有硬跑一个漂亮分数，而是先做出一套会承认“不知道”的实体底座，再开始真实连续采集。现在候选材料已经够90条，来源达到12个官方机构域和5类；系统也会直接告诉我们14个目录中有2个持续失败，而不会用“正文失败为0”掩盖它们。第一次受控DeepSeek合成调用也展示了同一种诚实：围栏里的5条内容单独看都能通过检查，但模型没有遵守唯一JSON和单终态合同，所以系统把它记成失败，而不是偷偷清理后宣布成功。归档盘或备份盘单独损坏时能从另一份重建当前文件快照。A-B-C接口会强制模型说明“依据什么、预计何时、怎样被证伪”，预测账本会在结果发生前锁住完整答案，新锚定器把答案和验证程序同时留在两块盘，第三方时间见证还能证明证据摘要何时存在。系统会严格区分“有人盖过时间章”和“这条预测确实早于事件”：DigiCert当前只能满足前者，Sectigo固定版本可限期满足后者的时间条件。但机械盘仍是exFAT，所以真实预测还不能获得正式前瞻资格；更没有证明模型说得对。“几周后发生的A能否正确唤醒此前B”也仍缺后两周查询锚点和双盲裁决。正式耐久归档、事实批准、重排和自主预测仍未开放。
