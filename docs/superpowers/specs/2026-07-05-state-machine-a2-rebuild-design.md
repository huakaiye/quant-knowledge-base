# 状态机式 A2 三关重构设计

> 本文档是 brainstorming 流程的 spec 镜像。研究库的权威载体是 [[02_研究方向/RD-20260705T082951Z-main-QQ4W_A2三关状态机式领先空仓信号重构|RD-QQ4W]] 与 [[04_实验记录/EX-20260705T083000Z-main-JM24_状态机A2重构kofn投票三信号组合预注册|EX-JM24]]，本文件提供从用户对话到设计决策的可追溯链条。

## 1. 问题陈述

### 1.1 当前实盘状态

v21（实盘 LIVE）= V20 + gap0.3。五层防线：

1. A2 三关空仓（LIVE）
2. A2-slope004 拥挤保留
3. B3-gate-tiered-v2 全弱降仓
4. gap0.3 普涨市旧仓保留（V21 新增）
5. 止损 8%

回测表现（2015-01-01 ~ 2026-05-19，cost2x，十一年持仓继承）：连乘 **35.52x**、12/12 年正收益、年化均值 +38.12%、MDD **-30.64%**。

### 1.2 核心病灶

A2 三关第三关依赖 `hs300_ma200 20 日斜率 < 0`。这是**反应式滞后**条件：

- 2015 牛顶见顶：2015-06-12（hs300 ETF 510300.SH）
- ma200 slope 首次转负：**2016-01-15**
- **滞后 = 214 天**（出处：[[04_实验记录/EX-20260629T145619Z-main-FXF4_A2基准标的风格错配只读诊断|EX-FXF4]] §12.3）

后果：**2015 全年 A2 空仓 0 天**，V21 在 2015 = 无 A2 baseline（+44.74% / -22.60%）。

### 1.3 为什么之前没解决

研究库已有 9 个方向尝试治理"反应式滞后"，**全部 park 或 kill**。归纳出 3 个共性失败模式：

| 失败模式 | 撞墙方向 |
| --- | --- |
| #1 "领先另一滞后指标"≠"领先市场见顶" | FXF4（kill）、JA43（park） |
| #2 组合层 alpha≈0，事件级有效被负控复制 | S2T4、JA43、CJC9、M3VC、2XKW、8AB7、A29 |
| #3 时段依赖（2025 强趋势误伤） | MCYG、CS dispersion、RA5 |

唯一未 park 的候选：**L3（距 ma200 < -3%）**，来自 [[04_实验记录/EX-20260629T152523Z-main-NBWM_A2反应式滞后量化与预警信号候选筛选|EX-NBWM]] 阶段 0.4 只读诊断，2015 领先见顶 +30 天、2025 未误报，但仅 L1_只读诊断等级、无 formal。

## 2. 设计目标

**主目标**：用 k-of-n 投票的状态机替换 A2 第三关的反应式斜率条件，在样本内（2015-2021）将 2015 回撤从 -22.60% 改善到 ≥ -15%，且样本外（2022-2026）不退化、2025 V 型不误报。

**次目标**：建立可复用的"领先空仓信号组合"研究范式，避免后续研究重复踩已 park 方向的坑。

## 4. 架构

### 4.1 状态机定位

```
v21 LIVE 不动
  ↓
回测层独立实验 EX-JM24
  ↓
状态机替换 A2 第三关的反应式斜率条件：
  - 触发动作：全切防御 ETF 511880.SH（二元空仓，与 A2 一致）
  - 与 B3 降仓、gap0.3、止损 共存，不冲突
  - 状态机优先级 > gap0.3（市场层先于持仓层）
```

### 4.2 三个信号

| 信号 | 定义 | 来源 | 默认阈值 |
| --- | --- | --- | --- |
| S1 = L3 距均线 | `(hs300_close - ma200) / ma200 < thr_L3` | EX-NBWM 唯一活信号 | -3% |
| S2 = 斜率缓冲带 | `0 < ma200_20日斜率 < thr_slope` | FXF4 阶段1.2 空白 | 0.0728%/日 |
| S3 = 死叉 AND slope近0 | `(ma60 < ma200) ∧ (slope < thr_slope_near0)` | JA43 §16.4 备选 | 0.05%/日 |

### 4.3 组合规则

```python
triggered_count = sum([S1, S2, S3])
state_machine_fires = (triggered_count >= k)  # 默认 k=2
```

### 4.4 与现有防线的优先级

```
1. 状态机触发 → 全切 511880.SH（替换 A2 第三关）
2. A2-slope004 拥挤保留 → 池内拥挤时保留旧仓
3. B3-gate-tiered-v2 → 持续全弱时降仓 60-80%
4. gap0.3 → 非拥挤分支保留旧仓
5. 止损 8% → 个股层止损
```

## 5. 数据流

```
CH 日线收盘价
  ↓
hs300_close / hs300_ma60 / hs300_ma200 / hs300_ma200_20日斜率
  ↓
S1 / S2 / S3 计算（T 日收盘后）
  ↓
k-of-n 投票（T+1 日 13:05）
  ↓
状态机触发 → 13:10 卖出 → 全切 511880.SH
  ↓
未触发 → gap0.3 判定 → 选股 / 保留旧仓
```

## 7. 测试与验证

### 7.1 样本划分

- 样本内（调参）：2015-01-01 ~ 2021-12-31
- 样本外（验证）：2022-01-01 ~ 2026-05-19

### 7.2 回测口径

- 十一年持仓继承（禁段初强制建仓）
- cost2x（slippage_bps=2.0）
- capital=100000，STOCK_SUM=1，MOMENTUM_DAYS=25

### 7.3 四道关卡

| 关卡 | 做法 | 通过标准 |
| --- | --- | --- |
| 错位一日负控 | 信号触发日延后 1 天重跑最优组合 | 真实改善下降 ≥ 50% |
| 随机打乱负控 | 打乱信号触发序列 100 次 | 真实结果 ≥ 95 分位 |
| 逐信号消融 | 分别去掉 S1/S2/S3 重跑 | 至少 2 个信号有边际贡献 |
| 邻域参数 CV | 最优点 ±1 档扫描 | CV < 10% |

### 7.4 成功与退出标准

**成功（全部满足才能 promote_candidate）**：

- ✅ 2015 回撤 > -15%
- ✅ 2018 / 2022 不退化（±2pp）
- ✅ 2025 收益 ≥ V21 × 90%
- ✅ 错位负控复制率 < 50%
- ✅ 邻域 CV < 10%
- ✅ 消融后 ≥ 2 信号有贡献
- ✅ 样本外连乘 ≥ V21 样本外连乘

**失败归因预案**：

| 撞墙 | 转向 |
| --- | --- |
| 失败模式 #2（负控复制） | 方案 C（regime-gated） |
| 失败模式 #3（2025 误报） | 加 V 型过滤（slop 仍正则不触发） |
| 失败模式 #1（2015 仍不触发） | 加更激进信号（L1 跌幅速率带 V 型过滤） |

## 8. 风险登记

| 风险 | 概率 | 影响 | 缓解 |

## 10. 范围外（YAGNI）

本设计**不包含**：

- 实盘部署（即便实验成功，仍需 2-3 个月 shadow 样本外验证）
- regime 分类器（属于方案 C，本实验失败后再考虑）
- 连续仓位函数（用户已明确选择二元空仓）
- 顺序状态机（用户已明确选择 k-of-n 投票）
- V 型过滤（仅在 F4 误报触发后才追加）
- 行业 / 个股增强信号（历史成分缺失，先走 ETF）
